# v1.0.0：首个硬件集成开发基线

状态：release candidate
发布日期：2026-10-06

## 版本定义

v1.0.0 冻结 A-NAS 第一个可运行、可测试、可回滚的只读硬件闭环：同一套 Web 桌面既能读取确定性 Fake 状态，也能经最小 Host Agent 读取 Debian 13 实机状态，并能在设备直连屏幕上常驻运行。

这里的 `1.0.0` 表示首个开发与硬件集成基线，以及当前 REST/OpenAPI 读取契约的 1.x 起点；它不表示消费级 NAS 已经完成。存储写入、共享、认证、数据保护、OTA 和 AI 能力均不在本版本承诺内。

## 交付范围

- `anas-api → hoststate.Reader → Fake/Linux Adapter → REST/OpenAPI` 的只读状态闭环。
- `/healthz`、系统、磁盘和原子聚合状态接口，以及 JSON 404、405、503 失败契约。
- React 桌面中的资源管理和系统设置；未实现应用保持禁用并标记“规划中”。
- 通过权限受限 UDS 提供状态的 `anas-host-agent`，以及超时、损坏响应、失联和取消处理。
- 内嵌 Web 资源的单一 Linux `amd64` 产品二进制和独立 Host Agent 二进制。
- 以 Git 提交为发布目录、以 SHA-256 校验制品、原子更新 `current` 并在失败时恢复上一版本的部署流程。
- Debian 13 上由用户级 systemd 常驻的 API 与 Host Agent，以及由系统级 Cage 会话承载、仍以 `anas-dev` 运行的本地控制台。
- Apple Color LCD 的设备配置：`DP-2`、`1536x2048@60.6Hz`、旋转 `90`、缩放 `1.5`。

- [Host Agent 测试](../../internal/hoststate/agent/agent_test.go)证明成功、Reader 失败、超时、损坏响应、Socket 不可用和上下文取消。

### Experimental NAS

- Debian 13 `amd64`、主机名 `a-nas-dev`；API、Host Agent 和 Kiosk 已同时保持 `active`。
- Live 状态只显示实际发现的 Acer 256 GB NVMe 系统盘和 57.7 GB 安装 U 盘，没有虚构未发现的 512 GB 数据盘；无 SMART 证据时健康保持 `unknown`。
- Host Agent 运行目录和 Socket 权限分别为 `0700`、`0600`；停止 Agent 后产品接口返回 `503 state_unavailable`，恢复 Agent 后自动恢复 Live 状态。
- 候选提交 `f010a90bd357` 已通过远端制品哈希核对、用户服务常驻和直连屏幕校准；root 管理的 `/etc/a-nas/kiosk.env` 已在服务重启后生效。
- 最终发布部署的提交、产品版本和哈希由远端 `releases/<git-sha>/RELEASE` 清单保存。

## 复盘

### 做对的事情

- 先冻结窄 `Reader` seam，再分别接 Fake、Linux 和 UDS Client Adapter，使 UI、产品 API 与宿主机实现保持解耦。
- 真实磁盘能力从只读开始，且把 `unknown` 当作一等状态，避免将缺失数据伪装成健康。
- NAS 只接收版本化制品，不保存源码、Node 依赖或 Git 工作副本；失败发布能恢复旧链接和服务配置。
- 实机事实随规格、ADR、调查记录和运行手册一起沉淀，新会话无需重新猜测 systemd、UDS 和 Kiosk 边界。

### 暴露的问题与改进

- `ProtectSystem=strict` 与进程自行创建运行时目录冲突；改由 systemd `RuntimeDirectory=` 声明唯一可写路径，详见[调查记录](../investigations/2026-10-06-host-agent-runtime-directory.md)。
- 系统级模板服务中的 `%h` 解析为 root home；Kiosk 改用明确的、受部署约束保护的 `anas-dev` 制品路径。
- 模板服务不能冒充 `display-manager.service` 别名；本地控制台改为图形目标的普通依赖。
- 显示器方向和缩放属于机器配置而非应用默认值；配置被移到 root 管理的 `/etc/a-nas/kiosk.env`，制品只携带可审计的实验机默认值。
- 首版 UI 曾用固定百分比和通知数装饰未实现数据；发布审查删除这些推断，并补齐设置页运行时间。以后只展示契约能够证明的事实。

## 已知限制

- 只面向设备所有者和开发者；没有认证、TLS 或 LAN/公网入口，API 只绑定回环地址。
- SSH 限定隧道属于可选远程诊断入口；它不是本地控制台运行的前提，必须按运行手册单独配置和验收。
- 512 GB 机械盘尚未被 Debian 发现；安装 U 盘仍连接。两者都不能在未确认稳定身份前执行写操作。
- 未安装或接入 `smartmontools`/`nvme-cli`，因此没有温度、SMART 或 NVMe 健康结论。
- 没有文件管理、用户/ACL、SMB、快照、备份、数据库、容器、AI、OTA 或恢复模式。
- 当前前端组件和 JSON 错误响应存在可接受的内部重复；在行为扩展前再拆分，不在发布收敛期做无需求支撑的重构。
