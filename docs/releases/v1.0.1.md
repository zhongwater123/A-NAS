# v1.0.1：实验 NAS 基础存储与共享闭环

状态：`v1.0.1-rc.N`；实机验收未完成，不得创建 `v1.0.1` 标签。

## 已实现

- SQLite/WAL 账号、会话、空间、文件目录、回收站、快照、存储计划与审计状态。
- 一次性管理员初始化、Argon2id、CSRF、管理员/成员与个人/共享空间 Policy。
- 三阶段稳定磁盘初始化、单盘 Btrfs、按 UUID 挂载、容量保留与离线卷拒写。
- root Host Agent 的类型化 UDS 操作，以及 root 所有的系统级发布与 systemd 单元。
- SMB3 账号、个人空间与 `Shared`，配置语法检查、原子替换和 Web/SMB 回收站对账。
- Web 文件管理、回收站、账号、存储初始化、磁盘健康和手动只读快照界面。
- OpenAPI 1.0.1 契约与 Go/React 自动化测试。

## 发布闸门

- 提交 `4e98e86b77c5` 已重新验证并冻结为 `v1.0.0`，其发布范围不被 v1.0.1 改写。
- 必须完成 [实机配置与验收手册](../runbooks/provision-v1.0.1-experimental-storage.md)中的全部门禁并保存证据。
- 在此之前只允许 `v1.0.1-rc.N`，只使用可丢弃测试数据。

`v1.0.1-rc.1` 在用户级过渡激活时暴露状态目录权限缺口，已拒绝发布并保留原标签；修复与证据见[调查记录](../investigations/2026-10-07-user-service-state-directory.md)，后续候选从 `v1.0.1-rc.2` 继续。

## 已知限制

单盘没有冗余或备份保证；Experimental NAS 已在线并在冷启动后识别 SATA 实验盘，但 Btrfs、Samba、SMART 和 systemd mount 尚未通过实机验收。运行中 SATA 热插拔与自动恢复作为后续任务，不阻塞本版；相册设计保留但实现暂停。
