# v1.0.1：实验 NAS 基础存储与共享闭环

状态：未发布。实机验收未完成，不得创建 `v1.0.1` 标签。最近的 RC 标签是 `v1.0.1-rc.5`（ADR 0008 之前的模型）；此后 Experimental NAS 部署的是未打标签的主干提交，进度见[当前状态](../status/CURRENT.md)。

## 已实现

- SQLite/WAL 账号、会话、空间、文件目录、回收站、快照、存储计划与审计状态。
- 仅需账号和密码的本机设备启用、Argon2id、CSRF、管理员/成员、个人空间与唯一 `Shared`。
- 统一 Linux 身份与文件系统 ACL（[ADR 0008](../adr/0008-use-unified-linux-identities-and-filesystem-acls.md)）：每个账号对应一个 UID 20100–29999 的 Linux 账号，ACL 是文件数据唯一的授权来源；Web 文件经 File Broker 以登录者本人身份读写，SMB 以同一身份访问，两者共用每用户回收站与同一密码；产品服务账号 `a-nas` 不能访问任何空间。
- 管理员查看模式（重新输入密码、填写原因、24 小时只读、审计并通知所有者）与管理员重置后的强制改密。
- 三阶段稳定磁盘初始化、单盘 Btrfs、按 UUID 挂载、容量保留与离线卷拒写。
- root Host Agent 的类型化 UDS 操作，以及 root 所有的系统级发布与 systemd 单元。
- SMB3 账号、个人空间与 `Shared`，配置语法检查、原子替换和 Web/SMB 回收站对账。
- Web 文件管理、回收站、账号、存储初始化、磁盘健康和手动只读快照界面。
- OpenAPI 1.0.1 契约与 Go/React 自动化测试。

## 发布闸门

- 提交 `4e98e86b77c5` 已重新验证并冻结为 `v1.0.0`，其发布范围不被 v1.0.1 改写。
- 必须完成 [实机配置与验收手册](../runbooks/provision-v1.0.1-experimental-storage.md)中的全部门禁并保存证据。
- 在此之前只允许 `v1.0.1-rc.N`，只使用可丢弃测试数据；实机验收应针对一个 RC 标签进行，证据才能复现。

`v1.0.1-rc.1` 在用户级过渡激活时暴露状态目录权限缺口，已拒绝发布并保留原标签；修复与证据见[调查记录](../investigations/2026-10-07-user-service-state-directory.md)。`v1.0.1-rc.2` 完成系统服务安装后暴露首次启用体验和 Samba 凭据创建故障；`v1.0.1-rc.3` 修复后完成首个管理员创建，但空白磁盘计划的 `null` 数组使 React 桌面蓝屏，且 Chromium 弹出密码保存提示。`v1.0.1-rc.4` 指向提交 `79851b862904`，修复两项问题并增加存储操作反馈；已有 RC 标签均保持不变。

rc.4 已在实机完成磁盘初始化，但暴露空间父目录不可遍历，以及个人空间/回收站缺少 Web 与 SMB 共同写入权限。证据、根因和 rc.5 修复见[数据卷空间权限调查](../investigations/2026-10-07-data-volume-space-permissions.md)；该修复让 `a-nas` 与用户共同持有空间，之后被 ADR 0008 取代。

## ADR 0008 升级后（2026-10-08）

- Experimental NAS 改为系统服务部署，旧账号按手册删除并重建为统一身份，ACL、身份镜像与 `a-nas` 被拒绝均已在实机核对，见 [ADR 0008 首次升级调查](../investigations/2026-10-08-adr0008-bootstrap-private-acl.md)。
- 部署后 Web 文件与终端不可用：Host Agent 在 systemd 下丢失 `CAP_SETUID`，修复后 Web 写入还会被产品服务的只读视图误拒，两者见 [issue #38 调查](../investigations/2026-10-08-host-agent-loses-setuid-under-systemd.md)。修复部署前，Web 侧验收不能开始。
- 旧 Samba 凭据已删除，管理员与成员各自改密后才能做 Windows SMB 验收。

## 已知限制

单盘没有冗余或备份保证；Btrfs 初始化与当前挂载已完成，但 Web/SMB 双向读写、回收站、快照、正常重启恢复、SMART 和 systemd mount 仍未完成整体验收。运行中 SATA 热插拔与自动恢复作为后续任务，不阻塞本版。相册、Docker 与应用中心已合入主干并部署在实验 NAS，但不属于本版验收范围。
