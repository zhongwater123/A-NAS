# 发布记录

发布记录冻结每个版本承诺的范围、验收证据、已知限制和后续入口。它不替代 Git 历史、当前状态、规格或运行手册。

## 规则

1. 版本标签使用带注释的语义版本标签 `vMAJOR.MINOR.PATCH`。
2. 发布记录必须说明“交付了什么”和“明确没有交付什么”，不能把开发预览描述为消费级正式产品。
3. 验收必须链接规格、自动化检查和实机证据；易变的当前状态仍由 [`CURRENT.md`](../status/CURRENT.md) 维护。
4. 发布标签创建后不改写；修复进入新版本。
