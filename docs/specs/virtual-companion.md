# 虚拟伙伴

状态：prototype（大肥鱼、番茄钟与简单待办、任务情绪反馈、网页小窝/电脑桌宠与成员状态接续；触屏 deferred）

更新时间：2026-11-03

## 目标

成员可以在伙伴小窝或桌面与同一个实验角色互动；小窝以聊天、专注计时和简单待办三个入口承载陪伴；桌宠可轻点打开聊天、拖动放下，通过更多菜单选择安静、收起与回小窝。形象层固定使用社区二创“大肥鱼”（dsh-pet 鲸尾女仆）精灵图验证功能，素材禁止商用，小窝底部附原作者地址；名字统一为大肥鱼，只有接口中的角色标识仍为 `naiwa`；旧实验形象配置保持可读，界面暂不提供切换。素材来源、摘要与使用边界见[素材说明](../../web/src/companion/assets/NOTICE.md)。

## 当前范围

- Web 桌面增加“伙伴小窝”，复用已有账号登录、启动器和窗口；小窝可将角色叫到当前网页角落，或叫回。
- 角色基础动画在本地运行，点击与物理反馈不调用模型；已移除躲猫猫、送花、抛接球、动作跟拍和呼吸游戏；支持键盘与减少动效。
- NAS 在 `companion.db` 中按登录成员保存形象、安静偏好、累计玩球次数、当前互动端和一个 VNAS 存储对话 ID。接口没有可选成员参数，不复制对话内容，也不执行文件或模型操作。
- 电脑桌宠通过 Electron 透明窗口运行，提供托盘、隐藏、显示、屏幕归位与窗口拖动；离线实验室复用网页的交互代码。
- 配置 NAS 地址后加载已部署本功能的 Web 页面。桌面端自行通过原有登录页认证，沿用自身会话；不复制系统浏览器 Cookie。打开“小窝”由同一 Electron 会话中的网页申请接续。
- 出现位置仍按客户端保存；角色形象、安静偏好和玩球次数跟随成员。网页小窝与同一页面的悬浮角色共享一个客户端身份，不互相争抢。

## 小窝工具与明确情绪

小窝使用小头像与三个工具页，默认“聊天”，另有专注计时、简单待办。原 VNAS 任务管理、确认卡入口和纪要工具收进“NAS 任务与记录”，运行时始终挂载。网页与原生桌宠外部只显示一条随角色移动的气泡和“聊聊 / 当前计时 / 更多”操作栏；点击大肥鱼或“聊聊”打开锚定操作栏的聊天面板，展开时隐藏外部气泡。连接说明与旧任务卡不再常驻叠放。

- **专注计时**：默认 25 分钟，可选 45 分钟或自定 1–90 分钟；支持暂停、继续、结束本轮及手动开始 5 分钟休息。使用绝对截止时间，页面重新加载、后台节流或系统睡眠后重新核对时间，完成只累计一次；休息不计入专注轮次。
- **简单待办**：最多 100 条，每条最多 160 字，支持添加、勾选和删除；未完成待办可一键开始 25 分钟专注。已有计时未结束时不能覆盖。到点只表示专注这一轮结束，待办完成必须由成员明确勾选或说出完整名称确认完成。
- **陪伴反馈**：专注时大肥鱼安静守时，到点提示伸懒腰和休息；切到同一浏览器的网页桌宠或同一 Electron 会话的小窝/桌宠时显示计时入口。提醒与待确认事项仍由原 VNAS 接口提供，真实任务反馈优先于本地计时文案。

计时、累计轮次和待办按账号写入当前设备的 localStorage，不写入 NAS `companion.db`，不调用模型，也不表示已经创建服务端定时任务；不同浏览器或电脑之间不承诺同步。页面关闭后不弹系统提醒，下次打开会按已保存截止时间恢复完成状态；浏览器禁止存储时仅保留当前页面数据并明确提示。到点在聊天中主动插入一条提醒，并显示可操作的提醒条；其他工具页也会显示到点提示，桌宠操作栏显示“到点啦”。同一截止时间在当前会话只插入一次；“知道了”的确认保存在设备内，刷新不重复报同一轮。当前版本不申请通知权限、不播放提示音、不抢焦点。

| 触发原因 | 表现与当场说明 | 下一步 |
| --- | --- | --- |
| 一轮专注到点 | 开心，并说明“这一轮专注完成” | 休息或再专注一轮；待办不自动勾选 |
| 休息到点 | 平静地询问是否开始下一件事 | 成员决定是否继续 |
| VNAS 协议报告本轮回答结束 | “开心 · 这轮回答完成啦” | 看结果；不等同于文件保存 |
| VNAS 报告任务出错 | “有点失落 · 这次任务没完成” | 点击进入聊天查看原因，6.5 秒后恢复平静 |
| VNAS 等待确认 | 期待地等成员决定 | 打开原 VNAS 确认卡，不自动决定 |
| 暂停、提前结束、安静或隐藏 | 平静陪伴 | 不扣分、不催促、不制造内疚 |

情绪不是随机切换。真实 AI 联动仅消费当前成员已绑定对话的 VNAS 状态、网关事件和确认卡；刷新历史不重播庆祝。本地计时和手动待办是独立的设备内工具，不由模型推测完成。原角色的点击、拖动和气泡跟随继续保留；旧 SQLite 活动记录保持兼容，不再生成玩球或游戏计数。触屏和形象重做继续延后。

## Personal agent：任务输入与主动回报

大肥鱼是成员自己的助手入口。小窝和桌宠共用聊天入口；明确的本机命令先执行计时或待办，其他请求通过现有 VNAS 对话交给已配置的 AI，沿用服务端定时任务与未读结果。真实模型经 Hermes 安排、唤醒并带回结果的本机检查见[运行时记录](../research/companion-reminder-runtime-check.md)，真实 NAS 的权限、文件和跨端验收仍不能由模型直连或前端协议测试替代。

### 聊天与本机工具

仅对成员主动发送的文字识别明确命令，不解析或执行 AI 输出中的命令：

| 成员输入 | 实际结果 |
| --- | --- |
| 专注25分钟 / 专注二十五分钟 | 开始 25 分钟计时；支持 1–90 整数分钟，不覆盖正在走或暂停的计时 |
| 专注 / 休息 | 追问分钟数，再执行对应模式 |
| 暂停计时 / 继续计时 / 结束计时 | 操作当前计时；提前结束不计完成轮次，已完成轮次不回退 |
| 帮我记一件事 | 追问内容；下一条补充写入待办，取消可退出追问 |
| 帮我记一下：写周报 | 直接保存本机待办，再回复收据 |
| 查看待办 / 完成待办：写周报 | 列出未完成事项 / 只勾选唯一完全同名项；同名或不完整时请用户在清单决定 |

问题、引用和复合计划不作为计时命令执行。聊天简史按成员在当前页面内共享，最多 30 条，刷新不恢复；实际计时和待办仍持久保存在设备。NAS 正忙时仍可执行本机命令，不自动排队或重试新的 NAS 工作。计时不需要模型，也不依赖伙伴跨端租约；NAS 请求仍受原租约、成员鉴权与确认卡约束。云端切到本地模型无需改这些工具的执行逻辑。

### NAS 工作

1. **交代事情**：输入“明早十点提醒我交材料”等请求，先保存对话引用，再交给现有 VNAS；不可互动、断线、运行中或有待确认卡时不能另发。示例只填入交代框，成员点“交给大肥鱼”才发送。提示要求定时任务使用现有 `cronjob`，核对 NAS 日期、时间与时区；“我的提醒与后台任务”直接读取服务端实际任务，支持原有的暂停、继续、立即运行与删除。下一次运行显示完整日期、时间和当前设备时区，模型口述“安排好了”不新增任务卡。
2. **交代工作并回来报结果**：例如“今晚整理这份会议记录，明早给我摘要”。复用原 VNAS 实例和确认卡，通知区分完成、失败、等待决定；结果必须有可打开的运行记录或文件。电脑关掉时由在线 NAS 处理，桌宠下次在线补看未读结果，不承诺电脑关闭时仍能在电脑上弹出提醒。
3. **有边界的主动发现**：指定文件夹上传完成等事件在成员授权范围内触发；不以模型反复轮询作为定时器。这部分需新增事件 Adapter，现有代码不等于已经支持。

后台结果复用成员的 `assistant_task` 通知。聊天面板显示最近一项未读结果，展开小窝的任务记录可看最近三项；每分钟读取一次，页面恢复可见时补读。新通知的 `ok` 状态触发“有新结果”的开心反馈，失败触发明确原因的失落反馈，持续约 6.5 秒；首次载入的历史未读结果保留卡片但不重播庆祝。忙、安静或伙伴在别端时不主动播报。刷新与重复读取不执行任务，未读结果仍保存在 NAS。

“查看结果”打开原 VNAS 运行记录，由原窗口记录已读；“知道了”只在服务端接受回执后清除通知，失败则保留卡片供重试，不代表用户已交材料等事项完成。小窝的“十分钟后再提醒”先填入新交代并明确要求发送，原结果保持未读；经 VNAS 实际保存后才算新提醒，不重跑原任务或改其重复计划。桌宠紧凑视图只提供查看和已读，重新安排从小窝发起。

通知缓存按成员隔离，换账号清空；旧账号的迟到读取和已读回执不改变新账号的显示。定时任务、NAS 唤醒和每成员运行记录沿用现有助手，不另起一套 Agent。外部网页、邮箱、日历等连接器需另行设计，现有助手规格限制不能默认为已放开。

说话气泡已和角色共享移动容器，拖动、滑行及主动移动时一起走；文字变化和场景边缘会重新计算位置，上方不足时放到下方。原生透明窗口高度为 400 像素；简短聊天可在桌宠弹层进行，完整对话和确认仍在 NAS 页面展开。

### 云端试验与本地目标

云端阶段使用用户已有的 Qwen 兼容 API，通过既有沙箱外模型网关接入；后续本地服务沿用同一 `/v1` 契约，调度、成员任务、确认卡、通知及大肥鱼交互独立于模型。接入配置包含完整 Base URL、模型 ID、独立凭据与已验证能力参数，不能把“兼容 API”当成工具执行可靠性的证明。

当前网关已支持路径前缀和回环本地无密钥模式，合成服务测试覆盖两条路线；Qwen 两款模型的 SDK 合成协议检查与运行时验收边界见[接入检查](../research/qwen-companion-capability-check.md)。4B 和后续较大模型均用同一组合成任务验证，默认本地失败不自动回退到云端。具体配置与检查见[云端联调与本地接入](../runbooks/try-ai-assistant-on-experimental-nas.md#qwen-云端联调与后续本地接入)。

## 接续规则

### 小窝 → 桌宠 → 小窝

打开 Web 小窝只观察，不抢占其他端。成员点“叫到这里”后才申请互动；电脑桌宠启动并登录后申请一次，后续通过按钮叫回。“到网页桌面陪我”只切换当前网页内的位置。

其他端在线时，新端显示“正在过来”，保持不可互动；旧端读到申请后先停止本地互动，再向 NAS 确认交接。NAS 原子地递增活动代次并授予新端；旧代次的玩球、续期和交接都被拒绝。桌宠“回小窝”打开或刷新小窝窗口，由小窝申请接续，旧端按同一规则交接。

旧端离线或页面隐藏、来不及确认时，新端等待其 15 秒租约到期后重新申请。不是点击后立即在两端同时激活。客户端按请求发出时刻计算保守截止时间，不使用跨设备的墙上时钟，也不因慢响应额外延长互动；即使读取挂起，到期后也会停下。

### 进度与冲突

申请携带状态版本，过期版本返回冲突；写操作携带当前代次和唯一事件 ID。最近 256 个事件内的同内容重试不会重复累计，复用事件 ID 改内容会被拒绝。客户端不自动重放离线玩球。

断线时显示暂停，可主动选“先在本机陪伴”，该模式的偏好不写入共享状态。连接恢复后需点“叫到这里”退出本地模式。旧版 NAS 或未启用状态存储的测试实例显示接续不可用，不能把本地偏好当作 NAS 同步。

### 退出与恢复

退出账号卸载小窝与悬浮角色，取消请求和排队中的写操作；再次登录按成员读取 NAS 状态。页面隐藏时停止轮询和互动，重新可见时恢复读取。服务端不靠浏览器关闭通知维持正确性，失去响应的旧端最终通过租约失效。

## 第一条任务流程：NAS 文本会议纪要

- 小窝列出本人个人空间与共享空间，排除管理员查看的其他成员空间；选择 32 KiB 以内的 `.txt` / `.md`。路径按 NAS 挂载名称构造并作为 JSON 引用，交给既有 VNAS `read_file` 读取，浏览器不另传文件内容。
- 通过既有 `useAssistantGateway` / `useAssistantThread` 创建或恢复对话，先用当前互动代次把存储 ID 记入 `companion.db`，成功后才 `prompt.submit`。保存失败或窗口退出不继续排队提交。只复用现有成员的 Hermes 实例、会话与工具规则，不另起一个 Agent。
- 首轮整理摘要与待办，不提交个人文件更改。点“保存到个人空间”继续同一对话，请 VNAS 走 `submit_changes`；这只是提交确认请求，用户仍须在原 VNAS 确认卡决定。桌宠不调用确认接口。
- 任务表现从真实连接、线程和确认卡记录推导：连接中、思考、处理、等待决定、回答结束、失败、停止。回答结束只代表本轮回答结束；“已确认保存”只采纳 `approval.status=applied` 且 `change.status=applied` 的写入、复制与移动记录，不采纳模型口述的文件路径。
- 已确认的个人空间文本文件可通过已有文件列表定位真实文件 ID，再使用认证的文本预览接口读取（预览上限 256 KiB）；其他位置与大文件回原 VNAS 或文件管理查看。此处不把模型输出转成下载 URL。
- 原生桌宠和网页悬浮入口通过气泡与聊天反馈任务状态；停止回答在小窝的 NAS 记录或原 VNAS 进行。桌宠聊天复用同一 VNAS 对话，确认与完整交互进入原 VNAS 窗口。原生 IPC 仅接受正常存储对话 ID，导航保持同一 NAS origin。
- 接续只共享对话引用；每端恢复同一对话及确认记录。互动租约到期不会取消后台任务；任务生命周期遵循现有 VNAS 成员实例规则，不承诺成员退出后无限后台运行。断线时停止新提交，重连恢复结果，不自动重放 prompt。
- 本次 SQLite 迁移为版本 1，旧活动次数、偏好、代次和事件去重记录保留。新字段不赋予任何对话读取权限；实际访问继续由既有助手成员鉴权校验。

## 非目标与待办

- **触屏待办**：现有硬件暂不支持；触控手势、公共与个人模式、共享屏幕身份确认及触屏实机验收均不在当前交付范围。
- 当前接续的是小型活动状态，不保存游戏的逐帧坐标、桌面布局、聊天记忆或物件库存。
- 当前有通用文字交代与文本纪要模板；语音按住说话、统一 TTS、跨设备专注同步、关系记忆、照片纪念卡和共同小作品后续接入。
- 系统其他应用的全屏自动避让、混合 DPI、多显示器连续甩抛与 Windows 原生验收待做。当前可从托盘主动隐藏；显示器变化时归位；电脑睡眠时隐藏，唤醒或解锁后恢复。
- 不后台读取其他应用、连续截屏、常开麦克风或自动访问用户资料；没有登录自启或自动部署操作。
