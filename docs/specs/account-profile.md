# 头像与昵称

状态：implemented
更新时间：2026-10-14

## 目标

让 NAS 上每个账号都能选一张头像、起一个昵称：头像可以来自这台电脑、NAS 上的文件或相册，保存时裁成圆形并压缩成小图，页面显示头像时不读取原图；昵称在桌面各处代替账号名显示，账号名仍用于登录、SMB 和 Linux。

## 非目标

- 不提供内置的头像图库或卡通形象；没有头像时显示名字的第一个字，颜色按账号名固定。
- 管理员不能修改其他成员的昵称或头像，也不能审核头像内容。
- 不改账号名：账号名是 Linux 与 SMB 用户名，规则见[统一身份与文件授权](unified-identity-and-file-acl.md#账号名与密码规则)。
- 不保留上传的原图，也不支持旋转和滤镜；浏览器打不开的格式（如 Chrome 中的本机 HEIC）需要先放到 NAS 上再选。
- 相册服务记录的上传者、反馈记录的作者等仍按账号名存储；页面在显示时换成昵称。

## 规则

| 项目 | 规则 |
|---|---|
| 昵称 | 去掉首尾空白、连续空白合并为一个空格后，最多 24 个字符（Unicode 码点）；不能含换行、制表符等控制字符或零宽、方向控制等不可见的格式字符，表情中的零宽连接符除外；不能与其他账号的账号名或昵称相同（不区分大小写）；留空表示不设昵称 |
| 头像 | 接受 JPEG、PNG、GIF、WebP，请求体最多 12 MiB、2500 万像素；服务端按 EXIF 方向转正、取中央正方形、缩到最多 256×256、透明处铺白，保存为质量 85 的 JPEG（通常几十 KB） |
| 可见范围 | 所有有效账号都能读取全部账号的账号名、昵称和头像（包括已禁用账号，它们的名字仍留在反馈和日志里）；角色与状态仍只有管理员能看到 |
| 存储 | 昵称和头像存放在产品服务的账号数据库（系统盘）中，数据卷离线时照常显示；头像版本是图片摘要，地址带版本，浏览器缓存一年不再请求 |

## 场景

### 设置昵称

- Given：成员 `alice` 已登录，尚未设置昵称。
- When：在“设置 → 我的账号 → 个人资料”点击“设置昵称…”，输入“ 小爱 ”并保存。
- Then：前端调用 `PATCH /api/v1/session/profile`，提交去掉首尾空白的“小爱”；成功后显示“昵称已改为“小爱”。”，页头、设置侧栏的账号卡片、系统快捷栏头像的名称提示和账号菜单都显示“小爱”，页头和账号菜单在旁边保留账号名 `alice`。超过 24 个字符或含不可见字符时不发请求并直接提示；名字已被他人用作账号名或昵称时显示“这个名字已经是其他人的账号名或昵称，请换一个”。清空后保存恢复显示账号名。

### 从本机图片设置头像

- Given：任一账号已登录。
- When：点击“我的账号”页头的头像（右下角相机标记）或“设置头像…”，在“本机图片”中选择、拖入或粘贴一张图片。
- Then：图片在对话框中打开为圆形裁剪框，可拖动位置、滚动或拖动滑块缩放（1–5 倍），右侧同时预览“我的账号”、系统快捷栏和问题反馈中三种大小。点击“保存头像”后，页面把选中的正方形以白底画成不超过 512 px 的 JPEG，`PUT /api/v1/session/avatar` 上传；服务端按上表再次压缩后保存。成功后对话框关闭，显示“头像已更新。”，所有显示该账号头像的位置换成新图。浏览器无法解码的图片不进入裁剪，提示改从 NAS 选择。

### 从 NAS 文件或相册选择头像

- Given：账号的个人空间或共享空间中有图片，或相册中有照片。
- When：在对话框中切换到“NAS 文件”或“相册”。
- Then：“NAS 文件”列出本人的个人空间和共享空间（不含管理员只读查看中的他人空间），按文件夹浏览，只显示文件夹和图片；HEIC 使用文件预览服务转换的大图进入裁剪。“相册”列出“我的图库”和“共享图库”的时间线，每次加载 120 张，可以“加载更多照片”；HEIC 照片使用相册的预览图。选中后与本机图片相同，进入裁剪和保存；读取均以当前账号的身份进行，看不到的内容不会出现。

### 移除头像

- Given：账号已设置头像。
- When：在“个人资料”的头像一行点击“移除”。
- Then：调用 `DELETE /api/v1/session/avatar`，显示“已移除头像，现在显示名字的第一个字。”，各处恢复为名字首字的圆形色块。

### 其他人看到的名字和头像

- Given：`alice` 的昵称是“小爱”并设置了头像，管理员 `owner` 的昵称是“爸爸”。
- When：任一账号查看系统快捷栏、问题反馈、日志、相册、文件管理或“用户与权限”。
- Then：桌面通过 `GET /api/v1/profiles` 读取所有账号的名字和头像，页面重新可见时再读一次。问题反馈的作者、编辑者和处理人，日志中的操作者与空间所有者，相册的图库名称，文件管理中只读查看的空间都显示昵称；问题反馈作者旁显示头像。管理“用户与权限”时每行显示昵称和灰色账号名，对话框和提示写作“小爱（alice）”；管理员只读查看或重置密码的账号通知写作“管理员 爸爸（owner）”。日志的搜索也匹配昵称；改昵称的记录写作“alice 把昵称改为 小爱”，并注明原来的昵称，更换和移除头像也各记一条。终端提示符和“以 X 的 Linux 账号运行”仍使用账号名。

## 边界与失败

- 三个写接口都需要会话和 CSRF 令牌，只能修改当前账号自己；被要求先改密码的账号在改密码前不能使用。已禁用账号不能修改。
- 头像 `GET /api/v1/users/{userId}/avatar` 需要登录：带当前版本 `v` 时返回 `Cache-Control: private, max-age=31536000, immutable`；不带版本时返回 `no-cache` 与 ETag，可用 `If-None-Match` 得到 304；账号没有头像时 404，页面退回首字色块。
- 服务端一次只解码一张图片，像素数先由图像头检查，避免解压炸弹；非图片或格式不支持返回 415 `unsupported_image`，过大返回 413 `image_too_large`。
- 账号资料读取失败时页面保留上一次的资料，名字退回账号名，不影响其他功能；账号自己修改后立即更新本地资料，不必重新读取。
- 新建成员时，账号名不能与已有账号的昵称相同（不区分大小写），否则返回 `username_unavailable`。
