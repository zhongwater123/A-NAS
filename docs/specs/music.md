# 音乐

状态：implemented（本地开发机验证，尚未部署）
更新时间：2026-10-12

## 目标

家庭成员在 Web 桌面的“音乐”窗口里收听自己放在 NAS 上的音乐：不需要导入或整理文件，A-NAS 自动把个人空间和共享空间里的音乐文件整理成音乐库、文件夹、专辑、类型和歌手，读取封面与歌词；每个成员有自己的最近播放、收藏和歌单。窗口采用左右双栏：左栏是搜索与导航，右栏是内容，底部是常驻的播放控制台。

## 非目标

- 不复制、移动、改写或删除音乐文件，也不编辑标签；管理文件仍在文件管理或 SMB 中完成。
- 不为节省带宽转码：浏览器能直接播放的 MP3、FLAC、AAC（M4A）、OGG Vorbis、Opus 和 WAV 都按原文件播放；只有 ALAC、APE、WMA、WavPack、AIFF 与 DSD（`.dsf`/`.dff`）这类浏览器不能播放的格式在播放时解码。不支持 CUE 分轨、TTA、MQA 与多声道下混设置。
- 不提供手机/DLNA/Subsonic 等外部客户端接口、在线歌词与封面下载、智能推荐、跨成员共享歌单。
- 关闭窗口即停止播放；不提供桌面级的后台播放器（最小化时继续播放）。

## 结构

- **左栏**：搜索框；“音乐库、文件夹、专辑、类型、歌手”；“我的”下的“最近播放、我的收藏”；“歌单”及新建按钮；底部的音乐库状态卡（歌曲数、整理进度、重新扫描、音乐文件夹）。窗口宽度不超过 760 px 时左栏收为图标栏，搜索改为图标并在搜索页显示输入框。
- **右栏**：音乐库是可按歌名、歌手、专辑、最近添加或时长排序的歌曲表；专辑、歌手是封面网格，类型是彩色卡片，进入后是带大封面的详情页和歌曲表；文件夹按音乐文件夹逐级浏览，可播放整个文件夹（含子文件夹）。详情页左上角有返回按钮。
- **播放控制台**：当前歌曲封面、歌名、歌手和收藏；随机、上一首、播放/暂停、下一首、循环（列表循环/单曲循环/播完停止）；可拖动的进度条（显示已缓冲部分）；歌词、播放队列和音量。
- **正在播放**：点击封面或歌词按钮，窗口进入深色的沉浸视图：大封面、背景取封面的模糊色彩，右侧歌词随播放滚动并高亮当前句，点击某句跳到该处。没有歌词时说明如何添加 `.lrc` 文件并显示歌曲信息。
- **播放队列**：右侧抽屉列出正在播放和接下来播放的歌曲，可拖动排序、移除、清空接下来，或把歌曲从列表拖进来。

## 场景

### 首次打开自动整理

- Given：成员的个人空间或共享空间里有音乐文件，例如 `音乐/歌手/专辑/01 歌名.flac`。
- When：成员打开“音乐”。
- Then：窗口立即显示已整理的歌曲并在后台开始扫描，左下角显示“正在读取歌曲信息 n / m”，新歌曲分批出现。读取标签（歌名、歌手、专辑、专辑歌手、类型、年份、曲目号、碟号），没有标签时用文件名，“歌手 - 歌名.mp3”同时得到歌手。旧版中文软件写入的 GBK 标签被正确识别为中文。MP3 的时长需要读取整首歌，排在标签之后计算。封面优先取内嵌封面，否则取同一文件夹（或 `CD1` 这类分碟文件夹的上一级）中的 `cover`、`folder`、`front` 等图片。

### 再次打开只读取变化

- Given：音乐库已整理过，之后通过 SMB 新增、改名、移动或删除了一些文件。
- When：成员再次打开“音乐”或点击“重新扫描”。
- Then：只有新增或内容变化的文件被重新读取；改名或移动的歌曲保留原有身份，收藏、歌单和播放记录不受影响；已删除的歌曲从音乐库消失。

### 播放浏览器不能播放的格式

- Given：音乐文件夹里有 ALAC（`.m4a`）、APE、WMA、WavPack、AIFF 或 DSD 文件。
- When：扫描到这些文件，成员播放并拖动进度条。
- Then：扫描时由媒体 Worker 读出它们的标签、时长与封面，列表中与其他歌曲一样显示，无损格式带格式标记。播放时媒体 Worker 把第一条音轨解码为 FLAC 实时送给浏览器：有损源（如 WMA）解码后无损封装，不会再次有损编码；24 位无损源保留 24 位；DSD 等高于 192 kHz 的采样率降到 176.4 或 192 kHz。拖动进度条时从新的位置重新开始解码，进度条按歌曲全长显示；暂停超过 30 秒后放开解码流，继续播放时从原位置重新开始。媒体 Worker 不可用时这些歌曲提示“设备暂时无法转码这个文件”并跳到下一首；开发环境没有 FFmpeg 时它们只按文件名收录。

### 播放与队列

- Given：任一歌曲列表。
- When：双击一首歌、点击“播放全部”或“随机播放”。
- Then：该列表成为播放队列并从所选歌曲开始播放；随机播放打乱顺序，关闭随机后恢复原顺序。右键菜单可以“下一首播放”“添加到播放队列”“添加到歌单”“收藏”“查看专辑/歌手”“歌曲信息”。播放超过 10 秒的歌曲记入最近播放。窗口最小化时继续播放，关闭窗口停止；下次打开恢复上次的队列与位置（暂停状态）。系统媒体键与耳机按键可以播放、暂停和切歌。

### 搜索

- Given：音乐库已有歌曲。
- When：在搜索框输入歌名、歌手或专辑的一部分，或输入拼音与首字母，例如 `zjl`、`qingtian`。
- Then：结果分为歌手、专辑和歌曲三组，名称越接近越靠前；多个词需要同时匹配。最近的搜索词保存在本浏览器中，可一键重复。

### 收藏、最近播放与歌单

- Given：成员已登录。
- When：点歌曲右侧的心形、播放歌曲、或新建歌单并加入歌曲（右键菜单或把歌曲拖到左栏的歌单上）。
- Then：收藏、最近播放（最多 300 首，可清空）和歌单只属于该成员。歌单可重命名、删除（不删除文件）、拖动排序、移除歌曲并可撤销；同一首歌可在歌单中出现多次。暂时不在音乐库中的歌曲（例如数据卷离线）保留在歌单里并提示“暂不可用”。

### 选择音乐文件夹

- Given：共享空间里还有有声书或录音，成员不希望它们出现在音乐库。
- When：在“音乐文件夹”中选择“只整理指定的文件夹”，从自己的个人空间或共享空间中挑选文件夹并保存。
- Then：音乐库、文件夹视图和搜索只包含这些文件夹（含子文件夹），并在后台重新整理；随时可以回到“个人空间和共享空间”。文件夹改名或移动后，下次扫描自动跟随。

### 空音乐库与故障

- Given：没有任何音乐文件，或数据卷离线。
- Then：没有音乐时窗口说明可以放音乐的位置、支持的格式，并提供“打开文件管理”“选择音乐文件夹”“重新扫描”；数据卷离线时说明需等待数据卷恢复。无法播放的文件提示原因并自动跳到下一首，连续失败三次后停止。

## 边界与失败

- **授权**：音乐库不是受管存储，而是对个人空间与共享空间里普通文件的索引（[ADR 0018](../adr/0018-index-music-in-place-through-the-file-broker.md)）。列目录、读取标签与封面、播放都经文件服务进行，生产中由文件代理以登录成员本人的 Linux 身份读取（[ADR 0008](../adr/0008-use-unified-linux-identities-and-filesystem-acls.md)），内核按 ACL 决定能否读取。成员只看到自己的个人空间与共享空间；管理员查看模式下看到的成员个人空间不进入管理员的音乐库。播放接口只接受音乐库中、属于调用者音乐文件夹的歌曲。
- **后台扫描**需要成员的会话：扫描在打开窗口或点击重新扫描时开始，会话结束即停止，下次打开继续。同一时间只有一个成员的扫描在读文件；扫描进行中再次请求只会在结束后再扫一遍。扫描状态只保存在内存中，产品服务重启后下次打开重新扫描。
- **派生数据**：歌曲索引与封面缩略图是派生数据，保存在产品服务状态目录（系统盘）的 `music.db` 与 `music-covers/` 中，可删除后由扫描重建。封面以内容的 SHA-256 命名，同一张封面只存一份 240 px 与 720 px 两种 JPEG；请求封面时只有调用者音乐库中引用它的歌曲才能取得。收藏、播放记录、歌单和音乐文件夹是用户数据，按成员保存在同一数据库中，以文件在空间内的稳定 ID 引用歌曲。
- **共享空间索引共用**：共享空间中同一文件的标签只读取一次，供所有成员共用。这依赖共享空间对所有成员可读；若管理员通过其他途径收紧了某个共享子文件夹的读取权限，成员仍可能在音乐库中看到其中歌曲的名称，但无法播放。
- **解析安全**：浏览器能播放的格式由 Go 库在产品服务进程内读取标签、封面和时长，单个文件的解析异常只跳过该文件；封面图片限 16 MB、5000 万像素，歌词文件只读前 1 MB。`.lrc` 与内嵌文本按 UTF-8 读取，失败时按 GB18030 读取。其余格式只由媒体 Worker 中的 FFmpeg 解析：每个请求一个无网络、看不到数据卷的独立进程，只收到成员身份打开的这一个只读描述符（[ADR 0017](../adr/0017-run-the-media-center-through-the-file-broker.md)、[ADR 0018](../adr/0018-index-music-in-place-through-the-file-broker.md)）。
- **媒体 Worker 不可用**：扫描时 Worker 暂时不可达，需要它的文件留到下次扫描再读，而不是以缺少标签的状态入库；完全没有 Worker（开发环境未装 FFmpeg）时这些文件按文件名收录、不能播放。播放请求返回 `decoder_unavailable`（503）或 `undecodable`（422）。
- **时长**：MP3 时长按帧计算，首次扫描大型 MP3 库需要读取每首完整文件；Opus 与裸 AAC 的时长由媒体 Worker 的探测补齐。

## 验收证据

- Go：[音乐库测试](../../internal/music/music_test.go) 用真实生成的 MP3（ID3v2 标签、GBK 文本、内嵌封面与 USLT 歌词）和 FLAC（Vorbis 注释）覆盖标签、封面、`.lrc`、按帧计算的时长、成员隔离、改名后保留身份与收藏、删除、音乐文件夹与歌单权限；[元数据测试](../../internal/music/metadata_test.go) 覆盖 GBK 修复不误伤拉丁文名、歌手与类型拆分、文件名推断和专辑分组；[HTTP 测试](../../internal/httpapi/music_test.go) 对照 [OpenAPI](../../api/openapi.yaml) 校验每个接口的请求与响应，并覆盖未登录、缺少 CSRF、Range 播放与带起点的解码流；[文件服务测试](../../internal/files/service_test.go) 覆盖按文件夹列出子树。需要解码的格式：音乐库测试用替身 Worker 覆盖探测标签（大小写与拼写不同的标签名、GBK）、24 位与 DSD 采样率的选择、超过结尾的起点、Worker 暂时不可达时留到下次扫描、没有 Worker 时按文件名收录；[媒体 Worker 测试](../../internal/mediaworker/worker_test.go) 覆盖 `audio` 请求的范围校验与 FFmpeg 参数。装有 FFmpeg 时 `TestRealFFmpegAudio` 与 `TestRealFFmpegDecodesThroughTheWorker` 用真实 FFmpeg 把 AIFF、WMA、WavPack 解码为 48 kHz/24 位 FLAC，并从真实文件读出标签与时长后经音乐库播放；已在 Debian 13 与 FFmpeg 7.1.5 的容器中通过。
- 前端：[音乐库模型测试](../../web/src/music/library.test.ts) 覆盖专辑、歌手、类型、文件夹的整理、排序、拼音搜索、LRC 与歌单排序；[窗口测试](../../web/src/music/MusicPanel.test.tsx) 覆盖加载并开始扫描、双击播放、拖动解码中的歌曲时带新起点重新请求、收藏、从右键菜单新建歌单与空音乐库。
- 浏览器检查：Fake 模式本地栈中用合成的 39 首示例歌曲（FLAC/WAV/GBK 标签 MP3、内嵌与文件夹封面、`.lrc` 歌词）检查首次扫描、播放与自动下一首、歌词滚动、拼音搜索、队列、专辑/类型/文件夹/歌手视图、新建歌单、音乐文件夹选择，以及 1440×900 最大化与 660 px 窄窗口布局；在 Debian 13 + FFmpeg 7.1.5 容器中运行的栈上，用 FFmpeg 生成的 ALAC（带封面）、WavPack、AIFF（ID3）与 WMA 检查了标签、封面、时长、播放与拖动后从新起点继续播放。
