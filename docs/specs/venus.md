# Venus

状态：draft
更新时间：2026-11-27

## 目标

Venus 是剪辑中心按《Venus PRD v3》改版后的产品：成员把一趟旅行的视频拖进来，AI 看懂每段画面，按一首歌的段落和拍点生成一支成片；成员逐个镜头精修，或者对助手说一句话，最后导出 1080p 下载。12-12 前上线初版，在实验 NAS 上内测（[#689](https://github.com/zhongwater123/A-NAS/issues/689)）。

本规格只写各功能共用的规则：作品状态机、本机文件、编辑模型与取段规则、分析、排队、示例作品、埋点、窗口大小、隐私与数据。各模块（PRD 的 M1–M10）的行为写在各自的规格里，链接到这里，不重复写。实现方式见[技术设计](../architecture/videocut-center.md#网页)。

PRD 和原型 `prototype-desktop-v3.html` 都不在仓库里。本规格与 PRD 不一致时以 PRD 为准（2026-11-27 用户决定），发现不一致就改本规格。PRD 前后矛盾的地方记在[待定](#待定)；标“默认做法”的条目是 PRD 没有写清、先按这里做的，产品可以改。

## 非目标

- 各模块的界面细节，例如候选网格的布局、提示文案。文案以 PRD 附录 A 为准，代码里集中放在一个文件。
- PRD 范围表里“延后”和“不做”的功能：重新生成、重新编排、多版本切换、延长一拍、合并相邻卡位、锁定与重洗、4K、链接分享、手机端、素材库，以及每个测试用户一个私有链接（PRD 把账号与数据隔离延后；在 A-NAS 桌面里项目本来就按登录账号隔离）。

## 用词

界面文案按 PRD 写；文档和代码按[领域语言](../../CONTEXT.md)写。对应关系：

| 界面上（PRD） | 文档里 | 说明 |
|---|---|---|
| 作品 | 剪辑项目 | Venus 的一个项目只有一条成片，界面上不切换版本 |
| 卡位 | 音乐槽 | 长度与切点由歌定，成员的任何操作都不改变槽数和总时长 |
| 镜头 | 镜头 | 时间线上一个音乐槽里放的那一段画面 |
| 片段、候选片段 | 节拍 | 卡片里的一段画面，规划和替换都以它为单位；和音乐的拍不是一回事 |
| 段落 | 段落 | 歌的结构段：前奏、主歌、副歌、尾奏，由配乐分析给出 |
| 锚点 | 锚点 | 见[领域语言](../../CONTEXT.md)；界面上不画标记 |
| 导出 | 导出 | 界面上的一个操作：按当前时间线渲染 1080p 成片并下载 |

## 作品状态机

一个剪辑项目在任一时刻处于下面一种状态。状态存在服务端，刷新页面、换标签页都不丢；网页按状态决定显示哪个页面（PRD 3.3、M10-1）。

| 状态 | 进入条件 | 开始页卡片上 | 点开进入 | 下一步 |
|---|---|---|---|---|
| 导入中 | 点“下一步”时还有文件没在本机读完 | 导入中 38/112 | 准备页，顶栏显示进度 | 读完 → 待生成；关掉页面即作废 |
| 待生成 | 全部读完，还没点“开始生成” | 待生成 | 准备页 | 点“开始生成” → 上传中 |
| 上传中 | 点了“开始生成” | 上传中 38/112 + 进度条 | 成片页生成中态 | 传完 → 排队中或生成中；断网重试 3 次仍失败、或关掉页面 → 上传中断 |
| 上传中断 | 上传中关掉页面，或断网重试 3 次失败 | 上传中断 | 准备页，提示条说明一次“上传中断，重新选择文件继续”；成员正停在成片页时也切过去（[决定](../decisions/2026-11-27-venus-prd-gaps.md)） | 重新选择文件 → 上传中 |
| 排队中 | 传完，但另一个项目正在生成 | 排队中 | 成片页生成中态，写“上一条完成后自动开始” | 轮到 → 生成中 |
| 生成中 | 传完，且没有别的项目在生成 | 生成中 62% | 成片页生成中态，三条进度 | 素材和歌都分析完后编排；完成 → 已完成；失败 → 失败 |
| 已完成 | 时间线生成完，或导出后又改过 | 已完成 · 0:30 | 成片页 | 改镜头、撤销留在已完成；点导出 → 导出中 |
| 导出中 | 点了导出 | 导出中 | 成片页，只读 | 渲染完 → 已导出，成片页开着时自动下载（见[边界与失败](#边界与失败)）；失败 → 已完成，并提示原因 |
| 已导出 | 渲染完 | 已导出 · 1:00 | 成片页 | 再改 → 已完成；再导出覆盖上一次的文件 |
| 失败 · 原因 | 上传整体失败、分析整体失败或生成失败 | 失败 · 服务繁忙 | 失败所在的页面，带重试 | 重试 → 回到失败的那一步 |

- 分析没有单独的状态：每段传完就开始分析（见[分析](#分析)），上传中、排队中、生成中都可能在进行，在成片页三条进度的第二条里显示。生成中要等全部素材和所选的歌都分析完，才开始编排。
- 任一状态下点“删除”：处理中的项目先停任务，再删除。删除时删掉哪些数据，见[隐私与数据](#隐私与数据)。
- 失败原因只用四个短词：网络中断、文件损坏、服务繁忙、素材不足。重试最多 3 次，之后提示“多次失败，请联系我们”。
- 导出失败后状态回到已完成，但失败原因和已重试的次数仍记在项目上，网页据此提示一次，并判断是否到了重试上限。生成完成时，跳过的段数也记在项目上，网页据此提示一次“N 段无法分析，已跳过”。

### 每个状态服务端存什么

接口契约按这张表定字段（PRD 3.3）：

| 状态 | 服务端存什么 | 保留多久 |
|---|---|---|
| 导入中 | 项目记录、[文件清单](#本机文件)与本机读出的元数据；文件本身只在本机 | 网页停止报到后作废，删掉记录 |
| 待生成 | 同上，加勾选、星标与设置，改一次存一次 | 到成员删除 |
| 上传中、上传中断 | 已传完的原片、代理片、缩略图；设置快照 | 到成员删除 |
| 排队中 | 全部素材，已出的逐段分析结果 | 到成员删除 |
| 生成中 | 逐段分析结果、卡片、向量 | 到成员删除 |
| 已完成 | 时间线、候选、锚点；撤销的那一步只在本次打开期间有效 | 到成员删除 |
| 导出中 | 时间线快照 | — |
| 已导出 | 成片文件 | 到成员删除；再导出覆盖 |
| 失败 | 已完成的部分 | 到成员删除 |

### 网页报到

关掉浏览器标签页时，网页来不及通知服务端，所以“导入中作废”和“上传中断”由服务端按报到判定（默认做法，数字写契约时可改）：

- 导入中和上传中的项目，打开它的网页每 30 秒向服务端报到一次；上传本身的进度也算报到。
- 导入中的项目 2 分钟收不到报到，作废并删掉记录。
- 上传中的项目 2 分钟既没有上传进度也没有报到，转为上传中断。

## 本机文件

导入只在浏览器本机读文件，点“开始生成”之前服务端没有任何视频文件（PRD M2、M3）。

- **文件清单**：项目在服务端只存文件清单：每个文件的名称、大小、修改时间，以及本机读出的时长、尺寸、横竖与拍摄日期。名称、大小、修改时间三项合起来认文件，用来去重，也用来在重新选择时对上原来的文件。
- **项目建立之前**：拖进开始页的文件先记在本机的一份清单里，点“下一步”时用它建项目。回到开始页时，导入面板显示刚才那份清单和进度，“继续选择”的文件加进同一个项目；这个项目点了“开始生成”后，面板回到空态（默认做法）。
- **首帧**：导入时解码一次，跟本机文件放在一起；准备页的按天概览和成片页的“添加素材 · 本机文件”都用它，换页面不重新解码。
- **关掉剪辑窗口**：本机文件、导入进度和上传都保留，重新打开窗口接着用。
- **刷新或关掉浏览器标签页**：本机文件全部失效。导入中的项目作废；待生成和上传中断的项目点开进准备页，提示“重新选择文件继续”。重新选的文件按文件清单对上，对不上的不算；对上的恢复原来的勾选和星标。
- **勾选、星标、设置**：待生成阶段改一次存一次，刷新后还在；点“开始生成”时存一份设置快照，之后不再改。
- **“添加素材 · 已导入素材”**（成片页 M7-4）：列的是本项目已上传、已分析的素材，缩略图从服务端取；准备页去掉勾选、没有上传的段不在里面。

## 编辑模型

歌 → 段落 → 音乐槽 → 镜头（PRD 3.1）。一首 1 分钟的成片通常有 4 到 6 个段落，每段 8 到 18 秒；每段按拍点切成若干音乐槽，一个槽占音乐的 1 拍或 2 拍，副歌切得密、前奏切得疏；每个槽放一个节拍（素材里的一段画面），就是一个镜头，镜头时长等于槽的时长。

- **生成**：目标时长是所选歌的主歌加副歌。导入的歌有拍点但分不出段落时，按整曲前 60 秒截到最近的小节；连拍点都没有，这首歌不可用。
- **选片**：考虑画质、段落情绪、大致按拍摄时间；相邻镜头不用同一段原片；同一地点不连续堆；星标的素材一定放进去；废片不入片；方向和成片比例不符的居中放、两侧模糊填充，或排到后面。
- **候选**：规划时为每个槽预留 6 到 8 个候选，排除已经在成片里的、方向不符的、与相邻镜头同一段原片的。界面最多显示 6 个。
- **素材不足**：需要的槽多于可用节拍时，允许用同一段原片的不同时刻；可用素材少于需要的一半时，提示“素材较少，成片可能重复”，仍然生成。

### 镜头操作

| 操作 | 音乐槽 | 内容怎么变 |
|---|---|---|
| 候选替换、搜索后放入、添加素材到轨道 | 不变 | 换这个槽的节拍，入点按取段规则 |
| 删除镜头 | 不变 | 这个槽换成下一个候选；不是去掉槽，去掉会让片子短一截、后面全部错拍 |
| 调整入点 | 不变 | 同一段原片换起始时刻 |
| 段落换序 | 不变 | 搬的是镜头内容：原段落的镜头按新位置的槽重新填，槽多出的从候选补，少了的去掉排在后面的 |

- **按槽指明位置**：每个镜头操作都指明是第几个音乐槽。槽的数量和位置不变，所以换序之后“第 N 个槽”仍是同一个位置，变的只是里面的内容。
- **修订号**：每次操作带上时间线当前的修订号；修订号对不上（例如两个标签页同时改）时服务端拒绝，网页重新读取时间线再让成员操作。
- **即时生效**：上面每种操作和撤销都立即生效，预览从改动的那一镜重放。一次只处理一条，处理中界面不接受下一条。
- **从本机添加素材**（M7-4 的“本机文件”）：上传和分析要几分钟，不占“一次只处理一条”的锁。这个槽的镜头卡显示“上传中 → 分析中”，槽里仍放着原来的镜头，期间可以改别的镜头。分析完后作为一次普通的镜头操作放进这个槽，算一步撤销，成为锚点。等待期间这个槽又被成员改过时不再自动放入，素材留在“已导入素材”里，并提示一次（默认做法）。上传中断时提示“上传中断”，槽里的镜头不变。
- **撤销**：只撤最近一步镜头操作；不撤设置、上传和导出；切换项目或刷新后清空。不做重做。
- **锚点**：被成员改过的镜头（候选替换、调整入点、添加素材、助手替换）成为锚点。之后的自动操作（删除后的补位、段落换序后的重新填充）不改锚点镜头。撤销一步时，这一步留下的锚点一起撤销。
- **候选用尽**：删除按钮不可点，不自动放宽到方向不符的候选。
- **生成开始后设置不能改**：想改设置，回开始页新建一个项目。

编辑模型以 PRD 为准，取代 ADR 0039 的修改稿：一个项目一条成片，只撤一步，导出覆盖上一次的文件，原因见 [ADR 0041](../adr/0041-edit-venus-films-on-one-timeline-per-project.md)。

### 取段规则

替换、添加素材和助手替换共用（PRD 3.1、M7-1）：

- 节拍比槽长：入点按优先级取，依次是规划入点、成员手动调过的入点、画质分最高的窗口、素材中间。
- 节拍比槽短：放慢填满，最慢 0.5 倍；还不够，换下一个候选。

## 分析

- 每段素材上传完就开始分析，不等整批，上传还没结束时“已分析”的计数已经在涨。
- 黑屏、误触、剧烈晃动三类废片不进成片；判不准的宁可留下。
- 单段分析失败自动重试，仍失败就跳过；生成完成后在成片页提示一次“N 段无法分析，已跳过”。
- 不做人脸识别与聚类，不做地点识别；文件自带的 GPS 只存不用。

## 排队

- 多个项目可以同时点“开始生成”，上传同时进行。
- 生成和导出各自一次只处理一个项目，后来的排队，显示“排队中 · 上一条完成后自动开始”。
- 导入的歌分析不阻塞“开始生成”；生成等这首歌分析完才开始编排。歌分析不出来时，提示换一首，并回到上一首。

## 示例作品

- 开始页作品列表的最后一张固定是示例作品，封面是平面山景，写“示例 · 0:30”；新成员的列表里只有这一张（PRD M1-1）。
- 示例作品不能删除，不显示“删除”。点开进示例的成片页。
- 所有成员共用系统内置的一份，只读：能播放、能点镜头看候选，不能改、不能导出（[决定](../decisions/2026-11-27-venus-prd-gaps.md)）。

## 埋点

初版不自己埋点（[决定](../decisions/2026-11-27-venus-prd-gaps.md)）：成员在页面上的交互由同事接入的热力图工具记录，模型调用由公司中台记录。PRD 3.6（M10-2）的事件清单以后用来核对这两处的记录够不够用。

## 窗口大小

Venus 在 A-NAS 桌面的剪辑中心窗口里，布局按窗口自己的宽高变化，不按屏幕（PRD M6-6 与横切规则）。

- **基准**：窗口宽 1200 以上。
- **成片页**：
  - 1200 以上，检查器固定 320 宽；
  - 1024 到 1199，检查器收成右侧一列图标，点开覆盖在播放器右侧，不挤压布局；没选中镜头时点镜头图标，提示“先在时间轴上点一个镜头”；
  - 900 到 1023，段落总览并入时间轴工具行，不能拖；
  - 高度不足 800，先压时间轴：音乐轴 36 高，镜头卡 72 高；
  - 播放器始终占剩余空间的最大，和时间轴同屏，不出纵向滚动。
- **开始页**：不足 900 宽时标题缩小，作品卡一行 2 张。
- **准备页**：左栏不足 520 宽时不显示缩略图和横竖标签，只留日期和勾选。
- **900 以下**：顶栏压缩，镜头轨在轨道内部横向滚动，整页不出横向滚动条；不足 720 宽时整页只显示“请放大窗口”（[决定](../decisions/2026-11-27-venus-prd-gaps.md)）。
- **布局稳定**：提示条覆盖在内容上方，不挤压布局；文字会变的按钮（导出与导出中、开始生成与生成中）固定最小宽度；切页面、切检查器、开关弹层都不改变其他元素的位置和尺寸。

## 隐私与数据

- 素材、代理片、成片和编排数据只有本人能看、能操作。
- 画面只以关键帧发给公司 AI 接口写描述，不发给其他外部服务。反馈组件现在所有账号共用一份清单，截图带画面，内测前要告诉测试者。
- 单个项目最多 200 段素材，单段最大 4 GB。
- 原片归相册：点“开始生成”后，勾选的原片传进成员的个人图库，和首版一样经项目授权使用（[ADR 0038](../adr/0038-keep-montage-media-in-the-photo-library.md)）；项目记着用了哪些原片，以及拍摄日期、时长、尺寸、横竖、首帧、星标，上传后再有分析结果。
- 删除项目：成片、时间线、候选、锚点和导入的歌一起删，删除后用原链接打不开项目、也下载不到成片；正在处理的任务先停。原片留在相册，不删（2026-11-27 产品经理确认，与 PRD 3.5 不同，见 [ADR 0041](../adr/0041-edit-venus-films-on-one-timeline-per-project.md)）。初版保留到成员自己删，内测结束后是否统一清理另议。

## 待定

PRD 没写清或前后矛盾、写接口契约前要定的：

- **待技术确认的 T1、T2、T4、T6、T7、T8、T11** 记在 [#689](https://github.com/zhongwater123/A-NAS/issues/689)，各自影响的模块确认后写进对应规格。本规格里关掉窗口后上传继续，是 T6 的默认做法；刷新后不记得本机文件，是 T2 的默认做法。

## 场景

### 生成完成后页面自动切换

- Given：成员打开一个生成中的项目，成片页显示三条进度
- When：服务端把项目状态改为已完成
- Then：成片页切到正常状态，提示“生成完成”；成员不用刷新，也不用点任何按钮

### 刷新后重新选择文件

- Given：一个待生成的项目，勾了 80 段，星标 3 段
- When：成员刷新页面，点开这个项目，重新选择同一批文件
- Then：准备页先提示“重新选择文件继续”；选完后 80 段的勾选和 3 个星标都还在

### 关掉标签页后上传中断

- Given：一个项目在上传中
- When：成员关掉浏览器标签页，过了 2 分钟从新标签页打开开始页
- Then：这个项目的卡片显示“上传中断”，点开进准备页，提示“重新选择文件继续”

### 删除镜头不改变总时长

- Given：成片 1:00，第 5 镜还有候选
- When：成员删除第 5 镜
- Then：第 5 个槽换成下一个候选，提示“已删除，补入下一候选”，成片仍是 1:00，后面的切点都还在拍上

### 换序不动改过的镜头

- Given：成员先替换了第 2 段里的 3 个镜头
- When：把第 2 段拖到第 4 段的位置
- Then：被拖动段落的镜头按新位置的槽重新填，那 3 个锚点镜头还在；总时长不变

### 处理中不接受第二个操作

- Given：成员点了一个候选，替换还没完成
- When：又点删除
- Then：删除不执行；替换完成后界面恢复可点

### 从本机添加素材时还能改别的镜头

- Given：成员在第 7 镜选了一个本机文件，镜头卡显示“上传中”
- When：成员替换第 3 镜
- Then：第 3 镜立即替换；第 7 镜分析完后自动换上新素材

### 导出中只读

- Given：项目在导出中
- When：成员点候选或删除
- Then：操作不生效，提示导出中；播放器仍然可以播放

## 边界与失败

- **关掉窗口**：上传继续，因为上传队列在桌面层，不随剪辑窗口关闭（T6 的默认做法）。**关掉浏览器标签页或刷新**：本机导入作废，上传中断；离开前浏览器会先确认。
- **生成与导出**：都在服务端，关掉窗口或页面不影响；再打开时按服务端状态显示。导出完成时成片页没有打开，就不自动下载，下次打开成片页时提示“点此下载”。
- **网络断开**：上传显示“网络中断，恢复后自动继续”；恢复后自动接着传。
- **浏览器拦截自动下载**：提示条改为“下载被浏览器拦截，点此下载”。
- **估时**：每 30 秒刷新，向上取整，最小“约 1 分钟”，不倒涨；超过估时 50% 时改为“比预计慢，仍在处理”。
