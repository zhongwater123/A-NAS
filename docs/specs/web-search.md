# 网页搜索

状态：draft
更新时间：2026-10-30

## 目标

成员在 A-NAS 桌面上直接搜索互联网，不需要自己安装或配置搜索引擎。NAS 用内置的 SearXNG 把一次查询同时发给多个公网搜索引擎，合并去重后在 A-NAS 自己的窗口中显示。网页搜索随系统安装、默认开启，管理员可以在设置中关闭（[ADR 0030](../adr/0030-ship-web-search-as-a-built-in-searxng-service.md)）。

## 非目标

- 不自建网页索引，不爬取网站；结果只来自随 release 打开的公网搜索引擎。
- 不保存搜索词或搜索历史：服务端不写日志、审计或数据库，浏览器也不保存；关闭窗口后不留下记录。
- 除管理员可以整体打开或关闭“种子”分类外，成员和管理员都不能选择、增减或配置引擎，也不填写任何引擎的 API 密钥；引擎与默认参数随 release 固定。
- 不下载：种子与磁力链接只显示、打开和复制，不交给 NAS 上的下载应用，NAS 也不参与 BT 传输。
- 不按网站过滤结果：不拦截某个网站，也不为某个网站单独接入引擎。
- 不做站内浏览：点击结果在新的浏览器标签页中打开原网页，与应用中心的外部链接相同。本机屏幕能否打开外部网址由本地控制台的浏览器策略决定，不在本规格中处理。
- 不让 VNAS 使用网页搜索；VNAS 是否联网另行决定（[AI 助手规格](ai-assistant.md#非目标)）。
- 不做按成员的内容过滤或家长控制；安全搜索按引擎各自的支持统一取中等。
- 不修改 SearXNG 的代码，也不提供它自带的网页界面；SearXNG 不对局域网或互联网开放。

## 默认引擎

首个 release 的候选列表如下，以实验 NAS 上的实测为准，表现差的不打开。Google 在上游仍不稳定，默认不打开。

| 分类 | 引擎 |
|---|---|
| 网页 | 百度、必应、搜狗、360 搜索、夸克、Yandex |
| 图片 | 百度图片、必应图片、搜狗图片、夸克图片、Yandex 图片 |
| 视频 | 哔哩哔哩、爱奇艺、AcFun、搜狗视频、360 视频、必应视频、YouTube、Dailymotion |
| 资讯 | 必应资讯、搜狗微信 |
| 种子（默认关闭） | 海盗湾、1337x、nyaa、BT4G、BTDigg、SolidTorrents、Kickass、TokyoToshokan |

视频结果标明所在平台（如“哔哩哔哩”“爱奇艺”），点击在该平台打开。种子分类由管理员单独打开（用户 2026-10-30 要求支持，用于测试能力边界）。

## 场景

### 打开并搜索

- Given：网页搜索已开启，成员或管理员已登录。
- When：从桌面、程序坞或“全部应用”打开“网页搜索”，在搜索框中输入关键词并回车。
- Then：窗口顶部是搜索框，打开时光标在框内；下面是“网页”“图片”“视频”“资讯”四个分类（管理员打开种子搜索后多一个“种子”），默认“网页”。每条网页结果显示标题、网址的域名、摘要、发布日期（引擎给出时）和提供结果的引擎；点击标题或域名在新标签页打开原网页（`rel="noopener noreferrer"`）。
- And：引擎给出的答案或信息框（如百科简介）显示在结果上方，相关搜索显示在结果末尾，点击即用它重新搜索。结果末尾有“下一页”。

### 图片、视频与资讯

- Given：已有一次搜索。
- When：切换到“图片”“视频”或“资讯”。
- Then：用同一关键词在该分类中搜索。“图片”是缩略图网格，悬停显示尺寸和来源域名，点击在新标签页打开来源页面；“视频”每条显示封面、标题、时长与来源；“资讯”按发布时间排列，可以限定“一天内”“一周内”“一月内”“一年内”。
- And：缩略图与封面经 NAS 代取，浏览器只向 A-NAS 自己请求图片；代取失败的位置显示占位图。

### 种子

- Given：管理员已打开种子搜索，已有一次搜索。
- When：切换到“种子”。
- Then：每条结果显示名称、大小、做种数与下载数、发布日期和来源站点；“复制磁力链接”把磁力链接复制到剪贴板，点击名称用本机关联的下载程序打开磁力链接，来源站点在新标签页打开详情页。
- And：管理员关闭种子搜索后，“种子”分类从所有窗口消失，正在显示的种子结果被清空。

### 部分引擎未响应

- Given：一次搜索中，有的引擎超时、出错或要求验证码。
- When：其他引擎返回了结果。
- Then：结果照常显示，结果上方用一行灰字写出未响应的引擎，例如“百度、夸克未响应”。
- And：引擎要求验证码时，SearXNG 暂停该引擎一段时间，A-NAS 不尝试绕过；暂停期间它也计入“未响应”。

### 没有结果

- When：所有引擎都已响应但没有结果。
- Then：显示“没有找到与“<关键词>”相关的结果”。
- When：所有引擎都未响应（例如 NAS 无法访问外网）。
- Then：显示“搜索引擎都没有响应，请稍后再试”和“重试”，不显示为“没有结果”。

### 搜索太频繁

- Given：一个账号刚连续搜索了 10 次。
- When：再次搜索。
- Then：显示“搜索太频繁，请稍后再试”，不向引擎发出请求。上限按账号计算，保护全家共用的出口地址不被引擎判为机器人。

### 设置中的网页搜索

- Given：管理员已登录。
- When：打开“设置 → 网页搜索”。
- Then：显示开关“网页搜索”及其状态（运行中、已停止、启动中），一行说明“搜索请求从这台 NAS 发往下列搜索引擎”和默认引擎列表（只读），以及“开源许可”：SearXNG 的名称、版本、AGPL-3.0 许可证全文与这一版本的源码下载，源码由 NAS 自己提供。
- And：下面是第二个开关“种子搜索”，默认关闭，网页搜索关闭时不可操作；旁边一行写明“种子站的结果多为未经授权的影视内容”。
- And：成员的设置中没有这一分区。

### 管理员关闭网页搜索

- Given：管理员在“设置 → 网页搜索”中。
- When：关闭开关。
- Then：NAS 停止搜索服务，此后不再访问任何搜索引擎；所有账号的桌面、程序坞与“全部应用”中不再出现“网页搜索”；已打开的窗口显示“管理员已关闭网页搜索”。重新打开开关后，图标与搜索恢复。
- And：开关在升级与重启后保持。

### 搜索服务暂时不可用

- Given：网页搜索已开启，但搜索服务正在启动、已崩溃或正在重启。
- When：成员搜索。
- Then：显示“网页搜索暂时不可用，请稍后再试”和“重试”；systemd 会自动重启服务。

## 边界与失败

- 只有已登录的账号能搜索，未登录返回 401；成员与管理员的能力相同。搜索服务只经产品服务访问：它只监听一个只有产品服务能连接的 Unix 套接字，没有 TCP 端口。
- 搜索词放在请求体中，从浏览器到产品服务、再到搜索服务都不进入 URL，因此不会出现在 Caddy、产品服务或浏览器的访问记录中。产品服务不记录搜索词，不写审计；搜索服务关闭查询日志与访问日志。
- 没人搜索时搜索服务不访问外网：启动时就联网的插件与引擎不加载。
- 每个账号最多连续搜索 10 次，之后每 2 秒一次，超过返回 429 和 `Retry-After`；被拒绝的搜索（无效、关闭、种子未开）不占次数。一次搜索在产品服务端最长等待 12 秒；单个引擎 5 秒超时，整次搜索 10 秒（SearXNG 的设置），超时的引擎计入“未响应”。
- 搜索服务只能连接公网地址：本机、局域网、链路本地与其他保留地址都被拒绝，只放行设备当前使用的 DNS 服务器。这样它不能被结果中的地址利用来访问家里或公司内网的设备；系统测试证明这一点。
- 缩略图代取只接受 SearXNG 为本次结果签名的地址，只返回图片类型，单张大小有上限；桌面的内容安全策略不为外部图片放开。
- 结果中的标题、摘要与网址一律按纯文本显示；只有 `http`、`https` 地址显示为链接，“种子”分类另外允许 `magnet:` 链接。
- 种子搜索的开关由产品服务执行并保存在产品服务的状态中：关闭时产品服务不向搜索服务请求这一分类，种子请求返回 403 和 `torrent_search_disabled`。
- 管理员关闭后，搜索与缩略图接口都返回 403 和 `web_search_disabled`，搜索服务处于停止状态；打开开关时由 Host Agent 启动服务。
- 网页搜索与 SearXNG 的设置都由安装器生成且只读，升级时重写；只有两个开关的状态跨版本保留。

## 验收证据

- 产品服务：对 Fake SearXNG 的接口测试，覆盖结果映射（含种子的大小、做种数与磁力链接）、部分引擎未响应、全部未响应、超时、限流、两个开关的关闭状态与未登录。
- Web：搜索、分类切换、翻页、未响应提示、空结果、种子分类的显示与消失、关闭状态与图标隐藏的组件测试。
- 系统测试：搜索服务只有产品服务能连接；它无法连接回环、局域网与保留地址；DNS 服务器变化后允许列表随之更新；关闭开关后服务停止，升级后仍关闭。
- 实验 NAS：搜索服务能连接公网（门禁不访问外网，只在这里验证）；在 NAS 的实际网络下逐个测量候选引擎的成功率与耗时，结果写入研究记录，作为默认引擎列表的依据。
