# 备份中心

状态：implemented
更新时间：2026-10-13

## 目标

把桌面上的“文件快照”窗口与规划中的“备份”入口合并为一个“备份中心”：用户在一处看清每个空间受到怎样的保护，按计划自动拍摄快照，并在误删、误改后按名称或按时间找回文件和文件夹。备份中心如实说明快照不能防范硬盘损坏，备份到其他硬盘仍在规划中。

## 非目标

- 不备份到 USB 外接盘、第二块硬盘或远程目标；必备备份集、介质与恢复流程见 [issue #27](https://github.com/zhongwater123/A-NAS/issues/27)，USB 存储见 [issue #25](https://github.com/zhongwater123/A-NAS/issues/25)。“外部备份”页只说明规划，不提供任何可点击的备份操作。
- 不提供整卷回滚，也不覆盖空间中现有的文件；恢复总是复制出新的条目。
- 不统计快照独占的磁盘空间（需要 Btrfs qgroup）；快照显示的大小是其中文件的总大小。
- 不做分级保留（例如“每小时保留一天、每天保留一周”）；每个空间一份计划，只保留最近若干份。
- 不为相册的受管图库拍摄快照；相册的备份随 #27 设计。

## 结构

桌面上只有一个“备份中心”图标，它沿用原“备份”入口的位置（ID `backup`），使用独有的青绿色图块与“盾牌加回拨时钟”标志；原“文件快照”图标不再出现。窗口左侧为导航：概览、快照、找回文件、定时快照，以及“备份到其他位置”分组下标有“规划中”的外部备份；底部显示整体保护状态与后台进行中的恢复。窗口宽度不足时导航收为抽屉。

备份中心只列出用户自己的个人空间与共享空间；管理员查看模式下看到的成员个人空间只在文件管理中浏览，不在这里管理快照。

- **概览**：保护环按空间分段着色（已开启定时快照为青绿，失败或数据卷离线为红，只有手动快照为橙，没有快照为灰），旁边给出结论、最近一次快照、下次定时快照与快照总数，以及“找回文件”“开启定时快照”。每个空间一张卡片，显示定时计划、快照数量、最近与下次时间和最近 14 天的快照条形图。页尾列出最近的快照，并提醒快照与文件在同一块硬盘上。
- **快照**：按空间切换；左侧按天分组的时间线标出每份快照的时间、手动或定时、文件数与总大小；右侧浏览所选快照的文件夹，可进入子文件夹、下载文件、恢复文件或文件夹。可管理的空间提供“创建快照”“删除”，定时快照另有“保留”，把它转为手动快照，不再被定时清理。
- **找回文件**：按名称在一个空间的全部快照中查找文件和文件夹。每个结果显示所在文件夹、是否仍在空间中，以及不同版本：大小与修改时间相同的文件视为同一版本，合并显示“保存在 N 份快照中”和时间范围，最新版本在前。每个版本都可下载或恢复。
- **定时快照**：每个空间一张卡片，开关、频率（每小时、每天、每周）、时间（每小时只选分钟）、星期与保留份数。修改先成为草稿，卡片底部出现说明与“还原 / 保存”，保存后才生效。卡片显示下次时间与上次结果。

## 场景

### 误删了一个文件夹

- Given：个人空间每天 03:00 拍摄定时快照，今天上午整个“合同”文件夹被删除并已清空回收站。
- When：在“找回文件”输入“合同”。
- Then：结果中的“合同”文件夹和其中的文件都标为“已不在空间中”；对文件夹点“恢复”，对话框默认恢复到它原来的位置“个人空间”，确认后文件夹及其全部内容以新条目出现，提示可打开文件管理，搜索结果随即更新为仍在空间中。

### 找回改坏之前的版本

- Given：“项目计划.docx”在过去两周被修改过两次。
- When：在“找回文件”搜索它。
- Then：列出三个版本，各自显示修改时间、大小与保存它的快照范围；选择较早的版本恢复时，原文件夹仍在则默认恢复到原位置，同名文件存在时对话框提示并建议“项目计划 (恢复 10-12 14.30).docx”这样的新名称，不覆盖现有文件。

### 默认就有定时快照

- Given：一个空间从未设置过定时快照（新建的个人空间、共享空间，或升级前就存在而没人设置过的空间）。
- When：调度器第一次看到这个空间，或用户打开“定时快照”。
- Then：它已按默认计划开启：每天 03:00 拍摄，只保留最新 14 份；计划从这一刻起算，已经过去的 03:00 不补拍。用户可以修改或关闭，保存过的设置（包括关闭）不会被默认值覆盖。默认计划由调度器记录，创建者为 `system`。

### 修改定时快照

- Given：共享空间使用默认的每日计划，管理员打开“定时快照”。
- When：选择每周、周五、03:00，保留 8 份，点“保存”。
- Then：卡片显示下次时间。此后每周五 03:00 拍摄一份定时快照；拍摄成功后，该空间只保留最新 8 份定时快照，更早的定时快照被删除，手动快照不受影响。切换频率时，若保留份数仍是原频率的默认值（每小时 24、每天 14、每周 8），随之换成新频率的默认值。

### 设备关机错过了计划

- Given：每天 03:00 的计划，设备从周一晚上关到周四早上。
- When：周四开机后产品服务启动。
- Then：一分钟内补拍一份定时快照，而不是补拍错过的每一次；下一次仍在周五 03:00。

### 数据卷离线时到了计划时间

- Given：计划时间到达时数据卷不可用。
- When：调度器尝试拍摄。
- Then：计划记录“失败 · 数据卷不可用”，概览与侧栏显示需要处理；15 分钟后重试，直到下一个计划时间。数据卷恢复后的重试成功即恢复正常状态。

### 成员浏览共享空间的快照

- Given：成员打开备份中心。
- When：切换到共享空间。
- Then：可以浏览、下载与恢复共享空间快照中的文件（恢复需要对目标文件夹有写权限）；“创建快照”不可用并说明由管理员创建；定时快照卡片只读。

### 大文件夹在后台恢复

- When：恢复一个文件较多的文件夹，超过约 1 秒仍未完成。
- Then：对话框提供“在后台继续”；关闭后侧栏显示“正在恢复”，完成或失败时以提示告知。中途失败时已恢复的部分保留在目标位置，提示中说明。

## 边界与失败

- 个人空间只由所有者创建、删除、保留和设置计划；共享空间只由管理员管理，所有成员可以浏览和恢复。管理员查看模式只读：不能为被查看的空间拍摄、删除快照或设置计划（`403`）。
- 有效账号的个人空间与共享空间都有默认计划；已禁用账号的个人空间不再自动拍摄，已有快照保留。计划时间按设备时区计算。调度器每分钟检查一次：计划在修改之后到达的最近一个时间点尚未被成功的拍摄覆盖时立即拍摄；同一时间点失败后 15 分钟重试。拍摄不需要用户会话，由 Host Agent 创建 Btrfs 只读快照，与手动快照相同。
- 定时快照命名为“定时快照 YYYY-MM-DD HH:MM”（拍摄时刻），创建者记为 `system`。每次成功拍摄后，删除该空间超出保留份数的定时快照并写审计 `snapshot.expired`；删除失败只记录日志，留到下一次。关闭计划不删除已有快照。
- 保留份数为 1–100；每份快照在目录中为每个文件保存一行，份数上限防止目录无限增长。频率仅限每小时、每天、每周，时间为 `HH:MM`，星期为 0（周日）到 6。
- 快照目录记录每个文件的大小与修改时间；更新前拍摄的快照没有修改时间，这些快照中的同名文件不合并版本，在界面上显示为“版本”。旧目录升级时补齐快照的文件数与总大小。
- 查找按名称包含匹配（ASCII 不区分大小写），名称完全相同的结果排在前面；最多返回 100 个路径、读取 5000 行快照条目，超出时说明结果不完整。“已不在空间中”依据文件目录判断，通过 SMB 刚做的改动在下一次目录对账后反映。
- 恢复由文件代理以用户身份写入：文件夹恢复先创建目标文件夹，再逐个创建子文件夹并复制文件。目标名称已存在时返回 `409`，不覆盖；空间不足、数据卷离线或权限不足时中止，已复制的部分保留。快照下载由 Host Agent 流式读出，不支持断点续传。
- 计划与快照列表从系统盘读取；数据卷离线时仍能查看计划，快照列表与恢复提示数据卷不可用。
- 备份中心每 60 秒刷新各空间的快照与计划，以显示后台拍摄的定时快照。

## 验收证据

- Go 测试：[快照计划与恢复测试](../../internal/files/schedule_test.go) 覆盖每小时计划只在设置后的时间点运行、同一时间点只拍一次、只保留最新 N 份定时快照且不删手动快照、保留转为手动、关机后只补拍一次、数据卷离线时记录失败并在 15 分钟后重试、每周计划的下次时间、所有者与管理员的权限、非法计划、文件夹整体恢复与同名冲突、按名称查找与版本合并、`%` 转义、快照下载，以及旧目录升级补齐文件数与总大小。[产品 API 测试](../../internal/httpapi/snapshots_test.go) 以会话驱动全部新接口并逐个按 [OpenAPI](../../api/openapi.yaml) 校验请求与响应，覆盖管理员查看模式下的 `403`。
- React 行为测试：[备份中心测试](../../web/src/backup/BackupCenter.test.tsx) 覆盖保护概览与只列自己的空间、恢复到原文件夹及同名时改名、计划草稿只在保存时提交且共享计划对成员只读、查找结果的版本与“已不在空间中”；[桌面测试](../../web/src/App.test.tsx) 确认桌面只有“备份中心”入口。
- 浏览器检查：Fake 模式预览中以两周的手动与定时快照检查概览、快照时间线与文件夹浏览、找回与恢复对话框（原位置、同名冲突、选择位置）、创建与删除确认、定时快照、外部备份说明、成员只读视图与窄窗口抽屉。
- 实机：按[实验存储手册](../runbooks/provision-v1.0.1-experimental-storage.md#功能验收)第 4 步在实验 NAS 上验证定时快照与文件夹恢复。
