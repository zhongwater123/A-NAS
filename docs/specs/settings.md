# 设置

状态：implemented
更新时间：2026-11-13

## 目标

把桌面上并列的“系统设置”“资源管理”“存储初始化”“账号管理”四个窗口收拢为一个“设置”窗口，管理员终端也收在其中：日常应用与低频、高风险的设备管理分开，同一份设备信息只展示一次，并让包括成员在内的每个账号都能自助修改自己的密码。

## 非目标

- 设置窗口组织各分区；分区涉及的产品 API、角色规则和审计由各自规格定义，权限由服务端执行。
- 不实现网络、SMB 或安全等新设置项，侧栏也不为它们留位置。日志分区的行为见[日志](logs.md)。
- 不提供存储计划的查询或恢复接口；刷新页面后未执行的计划仍按十分钟过期，见[基础存储与共享](basic-storage-and-sharing.md#数据卷初始化)。未执行的计划可以在向导中取消，见[硬盘用途与数据卷冗余](disk-roles-and-redundancy.md#边界与失败)。
- 不改变状态栏、强制改密页和账号通知；状态栏不作为设置入口。
- 设备实时用量、短时趋势和服务与进程监控由[任务管理器](task-manager.md)定义。

## 结构

| 分区 | 成员 | 管理员 | 内容 |
|---|---|---|---|
| 我的账号 | 可用 | 可用 | 头像、昵称与账号名（见[头像与昵称](account-profile.md)）、角色（状态不正常时一并显示）、修改密码（同步 SMB 凭据）、本次登录方式与有效期、登录记录、退出登录 |
| 概览 | 可用 | 可用 | 页首是设备本身：一幅按非系统盘数量画出盘位的设备图（盘位指示灯随该盘健康变色）、设备名和系统健康；数据来源为模拟时标出。其下并排三项数字：存储空间（可用空间与用量条，整块点击进入“存储”）、最高温度（处理器、显卡与硬盘中最高的一项及其来源）、已运行时间与开机时间。再往下是需要处理什么（有问题时逐项列出原因、处理办法与“在存储中查看”，见[系统健康](system-health.md)；没有问题时不单列）（管理员另见“有新版本”一项，点开进入“系统更新”，侧栏的“系统更新”同时带一个标记）和细节（温度与风扇，见[设备温度与风扇](device-temperatures.md)；产品版本、操作系统、架构、系统盘空间、可复制的设备标识与状态更新时间） |
| 任务管理器 | 只读 | 只读 | 设备运行状态（总览、CPU、GPU、NPU、内存、网络、硬盘）与服务、进程资源用量，见[任务管理器](task-manager.md) |
| 存储 | 只读 | 可用 | 数据卷状态、冗余方式、容量与转换进度、磁盘列表；尚无数据卷时管理员可初始化数据卷，有未使用的硬盘时可设置它的用途（见[硬盘用途与数据卷冗余](disk-roles-and-redundancy.md)） |
| 系统更新 | 不显示 | 可用 | 更新状态与一个下一步操作、版本、自动下载与自动安装、最近 10 条记录、回到上一版本，见[系统更新](system-update.md) |
| 个性化 | 不显示 | 可用 | 全体账号共用的桌面壁纸与样式、本机屏幕的息屏时长，见[个性化](personalization.md) |
| 用户与权限 | 不显示 | 可用 | 账号列表、添加成员；每个成员的“更多操作”菜单提供重置密码、只读查看个人空间或私有图库、禁用 |
| 日志 | 只看自己的活动 | 可用 | 活动记录与系统日志，见[日志](logs.md) |
| 终端 | 不显示 | 可用 | 以管理员本人 Linux 账号运行的设备 Shell，见[Web 桌面终端](web-terminal.md) |

侧栏从上到下是搜索框、当前账号（头像与昵称，进入“我的账号”）和分区列表，顺序是概览、存储、系统更新、任务管理器、用户与权限、个性化、网页搜索、日志、终端，各项间距相同；窄窗口下它们按设备、家庭、诊断分成三张卡片。每项带线条图标，当前分区以白色底块标出、图标变为强调色。侧栏是透出桌面壁纸的磨砂玻璃，并向上延伸到标题栏左侧；内容区不透明。

内容区一次显示一个分区：标题在滚动时留在顶部并缩小，其下是居中的分组卡片，宽窗口下不无限拉伸；“终端”例外，深色终端占满内容区的宽度和高度。标题下不写说明文字。能点开的设置是整行可点的行，修改在设置窗口内的对话框中完成，结果以窗口底部的提示显示。

设置窗口变窄（640 像素以下）时一次只显示一栏：分区列表，或带返回按钮的分区。任何宽度下都能切换分区。

## 场景

### 从桌面和系统栏进入设置

- Given：任一角色已登录桌面。
- When：查看桌面图标，点击“设置”图标或系统快捷栏的齿轮按钮。
- Then：桌面只有一个“设置”图标，不再出现“系统设置”“资源管理”“存储初始化”“账号管理”，规划中的“日志”和原来的“终端”应用也已并入设置；两个入口打开同一个“设置”窗口。首次打开显示“概览”，同一页面会话内关闭后再打开回到上次的分区。已保存的桌面图标顺序中被移除应用的记录被忽略，“设置”沿用原“系统设置”的位置。

### 从头像进入我的账号

- Given：桌面已打开。
- When：点击系统快捷栏中的头像，在账号菜单中选择“我的账号”。
- Then：打开或聚焦“设置”窗口并切换到“我的账号”。账号菜单的其余行为见[系统快捷栏](system-rail.md#账号菜单与退出登录)。

### 搜索设置

- Given：任一角色打开设置。
- When：在侧栏的搜索框中输入“密码”或它的拼音 `mima`。
- Then：分区列表换成匹配的设置项，每项标出所在分区，只列出当前角色能看到的分区中的项目；方向键移动选中项，回车或点击后切换到那个分区，把对应的行滚动到可见处并短暂标出。没有匹配时显示“没有找到”。清空搜索框或按 Esc 回到分区列表。

### 自助修改密码

- Given：成员 `alice` 已登录，且没有被要求强制改密。
- When：在“我的账号”点击“密码”一行，在对话框中输入当前密码和两次相同、符合[密码规则](unified-identity-and-file-acl.md#账号名与密码规则)（12–64 个字符，不含控制字符）的新密码并保存。每个密码框都可以切换为显示明文。
- Then：前端调用 `POST /api/v1/session/password`，成功后关闭对话框并提示“密码已更新，SMB 凭据已同步。”；取消则关闭对话框且不发请求。两次新密码不一致时不发请求，提示“两次输入的新密码不一致”；新密码不合规时不发请求，直接提示原因；当前密码错误等服务端错误按错误码显示中文说明。管理员使用同一入口。管理员重置过本账号的密码时，“密码”下方一直显示最近一次由谁、何时重置，确认通知后也不消失。“本次登录”一行说明会话方式：本机屏幕登录在退出前一直保持，浏览器登录显示到期时间；其下“登录记录”一行打开“日志”并只显示登录类记录。昵称同样在对话框中修改；头像点击页首的头像更换，已设置头像时其下有“移除头像”。

### 角色决定可见分区

- Given：成员登录。
- When：打开设置。
- Then：侧栏只有“我的账号”“概览”“任务管理器”“存储”“日志”和规划中项目；“存储”显示数据卷与磁盘但没有初始化入口；“日志”只有自己的活动记录；“系统更新”“个性化”“用户与权限”和“终端”不出现。管理员看到全部分区。

### 概览保留设备状态的读取语义

- Given：任一角色打开“概览”。
- When：首次读取尚未完成、首次读取失败、刷新失败或观测过期。
- Then：分别显示加载态、带“重新连接”的空态、保留上次数据的“连接中断”横幅和过期提示，与 [Web 桌面宿主机状态](web-desktop-host-state.md)一致；刷新按钮立即重新读取 `/api/v1/host-state`。

### 存储按数据卷状态展示

- Given：打开“存储”，且数据卷存在。
- When：页面载入。
- Then：显示数据卷状态（在线、转换中、创建中、离线、只读）、冗余方式与组成它的硬盘、已用与总容量和文件系统 UUID；容量或已用空间观测缺失时显示为未知，不得显示为已满。磁盘列表显示型号、角色（系统盘、数据盘、未使用）、其他系统留下的“旧数据”、接口、介质、稳定 ID 短码、容量、健康和温度，不能使用的未使用硬盘写明原因；没有磁盘时显示“未检测到磁盘”。服务端只允许一个数据卷，因此不显示初始化入口；有合格的未使用硬盘时，管理员看到“发现 N 块未使用的硬盘”和“设置用途…”，行为见[硬盘用途与数据卷冗余](disk-roles-and-redundancy.md)。

### 尚无数据卷时初始化

- Given：数据卷列表为空。
- When：成员或管理员打开“存储”。
- Then：数据卷位置显示“尚未创建数据卷”的说明卡片。成员只看到请联系管理员初始化的说明；管理员看到“初始化数据卷…”，点击后在原位置展开三步向导：
  1. 选择磁盘：列出未分配磁盘，可以勾选一块或多块，不合格的磁盘不可选并显示拒绝原因；只有一块合格磁盘时自动选中；页脚提示所选磁盘的数据会被清除。没有未分配磁盘时说明候选盘的条件。勾选两块及以上时多出“冗余方式”一步，默认镜像。
  2. 核对计划：显示目标磁盘、身份指纹、将清除的签名、有效期与剩余分钟数和逐条动作，输入完全一致的确认短语后才能确认计划。
  3. 执行：红色说明“执行后无法撤销”，确认后显示进度并提示不要关机。

  完成后显示“数据卷已创建”，点“完成”回到数据卷卡片。计划过期显示“重新开始”；失败或需要人工处理时显示原因，并提示先按运行手册导出日志，不要立即生成新计划。向导页头始终显示计划状态的中文与原始状态码。

### 切换分区或关闭窗口不丢失存储计划

- Given：管理员已生成或确认一个存储计划，或计划正在执行。
- When：切换到其他分区、最小化或关闭设置窗口，再回到“存储”。
- Then：计划、已输入的确认短语和执行进度仍然显示，执行结果在返回后可见。服务端没有查询计划的接口，所以计划状态保存在桌面会话中而不是分区内；刷新页面或退出登录后丢失，计划按有效期自然过期，再生成的新计划会取代它。不想继续时，执行前随时可以“取消计划”离开向导并立即重新开始。

### 管理用户

- Given：管理员打开“用户与权限”。
- When：创建成员、重置成员密码、禁用成员，或开始只读查看个人空间或私有图库。
- Then：行为与[统一身份与文件授权](unified-identity-and-file-acl.md)一致。每行显示头像和昵称，设置了昵称的在旁边以灰色显示账号名，对话框与结果提示写作“昵称（账号名）”。“添加成员”在页头，对话框在账号与初始密码下方写明[规则](unified-identity-and-file-acl.md#账号名与密码规则)，不合规或保留的账号名、不合规的密码在提交前提示，账号名按小写创建；其余操作收在每个成员行的“更多操作”菜单中，选择后在设置窗口内弹出对话框完成，不使用浏览器弹窗。禁用账号必须在对话框中再次确认，并说明对方将无法登录网页和 SMB、已建立的 SMB 连接会断开、文件不会被删除。管理员本人那一行标记“你”，只提供跳转到“我的账号”并打开修改密码对话框的按钮。角色显示为管理员或成员；状态不正常时在角色后显示创建中、已禁用或凭据异常。列表下方说明只读查看的审计、通知与 24 小时自动结束规则。

## 边界与失败

- 分区可见性只是界面组织；成员直接调用账号、格式化或终端接口仍由服务端返回 `403`。
- 设置窗口的分区在当前页面会话内记忆，刷新页面后回到“概览”，与其他窗口布局一样不持久化。
- 其他分区切换时卸载；“终端”打开过一次后保持挂载，切走时只隐藏，所以 Shell 在设置窗口关闭前一直运行，行为见[Web 桌面终端](web-terminal.md#切换分区与最小化保留会话)。
- 每个分区独立显示自己的读取或操作错误，一个分区失败不影响其他分区和桌面；渲染异常由窗口错误边界接住。对话框内的操作失败时错误显示在对话框中，对话框保持打开；处理中不能关闭对话框。
- 菜单与对话框可用 Esc 关闭，点击菜单外部关闭菜单，点击对话框外的遮罩关闭对话框。菜单可以用方向键选择；Tab 在对话框内循环，对话框打开时桌面上的其他窗口照常可用。
- 切换分区后内容区回到顶部。
- 界面上不放注释性文字：分组卡片外没有脚注，行内只写状态和数据，不解释规则或实现；这些原因写在代码注释和规格里（2026-11-11 用户要求）。操作的后果写在执行它的对话框里；不可撤销的磁盘操作和“种子搜索”的提醒保留。
- “存储”的磁盘列表与“概览”共用同一个宿主机快照，不额外轮询。
