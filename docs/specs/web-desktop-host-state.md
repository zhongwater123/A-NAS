# Web 桌面宿主机状态

状态：implemented；local-console confinement pending

本规格描述 v1.0.0 的只读桌面基线。之后交付的认证、文件、相册、Docker、应用中心、终端与设置以各自规格为准，下文“非目标”只适用于该基线。原“资源管理”与“系统设置”窗口已并入[设置](settings.md)。
更新时间：2026-10-10

## 目标

设备所有者通过 A-NAS Web 桌面查看一次原子观测的系统与磁盘状态，明确区分模拟数据、实时主机、未知健康和连接中断；该页面只读且不把尚未实现的应用伪装为可用。

## 非目标

- 不实现身份认证、TLS、公网或局域网直接开放。
- 不实现文件、备份或 AI 应用；对应启动器只显示“规划中”。容器管理见[容器管理规格](container-management.md)。
- 不保存窗口位置，不在服务端或多设备间同步桌面图标顺序（数据库尚未决策）；触摸屏暂不支持拖动排序，以保留图标区的原生滚动，不执行 SMART、挂载、分区、格式化或其他宿主机写操作。

## 场景

### 通过桌面读取模拟状态

- Given：产品服务使用 Fake Adapter。
- When：浏览器打开桌面并在[设置](settings.md)中查看“概览”和“存储”。
- Then：两个分区显示 Debian 13、确定性磁盘和“模拟数据”，并且数据来自同一个 `/api/v1/host-state` 快照。

### 未评估的健康保持未知

- Given：实时系统或磁盘健康为 `unknown`。
- When：界面展示状态。
- Then：使用中性的“未知”，不显示为绿色健康，也不推断 SMART 结果。

### 连接失败时保留最后观测

- Given：至少成功读取一次，后续刷新返回 503 或网络失败。
- When：轮询或手动刷新完成。
- Then：保留最后成功数据并显示连接中断；恢复后自动替换为最新状态。

### 管理桌面窗口

- Given：设置或其他应用窗口已打开。
- When：用户拖动、缩放、最小化、恢复、最大化或关闭窗口。
- Then：窗口在当前浏览器会话中按操作变化；刷新页面后回到默认布局。

### 调整桌面图标顺序

- Given：桌面显示可用和规划中的应用图标。
- When：用户用鼠标或触控笔把图标拖到另一个位置，或聚焦图标后按 Alt 加方向键。
- Then：其他图标平滑让位，松开后顺序立即生效并保存在当前浏览器（`localStorage` 键 `a-nas.desktop-order.v1`），刷新或重启 Kiosk 后保持；拖动结束不会打开应用，Esc 取消拖动并恢复原顺序；读屏软件播报“已将…移动到第 N 位”。规划中的图标同样可排序；新增应用追加到末尾，已移除应用的记录被忽略。

### 通过程序坞切换焦点应用

- Given：至少一个应用窗口已打开。
- When：用户查看屏幕下方中央的程序坞并点击其中的图标。
- Then：程序坞只显示与桌面图标同款配色的应用图标，不显示应用名称文字；当前焦点应用的指示条加宽，后台应用显示实心圆点，已最小化应用图标变暗并显示空心圆点。点击后台应用切换为焦点，点击已最小化应用恢复并聚焦，点击当前焦点应用将其最小化；无障碍名称分别为“切换到…”“恢复…”“最小化…”。

### 未实现应用保持不可用

- Given：文件、备份或 AI 功能尚未交付。
- When：用户查看启动器。
- Then：入口禁用并标记“规划中”，不会出现虚构的可用状态。

### 桌面时钟持续跟随系统墙钟

- Given：Web 桌面保持打开并跨过一个或多个分钟边界。
- When：浏览器的系统墙钟前进或被操作系统校正。
- Then：顶部时钟在下一个分钟边界重新读取当前时间，不冻结在页面首次渲染值，也不累计 timer 延迟。

### 使用设备桌面壁纸

- Given：Web 桌面显示在浏览器或比例不同的本地控制台屏幕上。
- When：桌面背景完成加载。
- Then：使用 A-NAS 的 4:3 深蓝抽象静态壁纸，居中并按 `cover` 覆盖可视区域；允许边缘裁切，但不出现黑边、拉伸或平铺。

### 在 NAS 直连屏幕使用同一桌面

- Given：Experimental NAS 连接屏幕、键盘和鼠标，Kiosk 会话已安装。
- When：设备进入图形启动目标。
- Then：Cage 中的 Chromium 以 `anas-dev` 打开回环地址上的同一 Web 桌面，不出现通用桌面、浏览器导航界面或额外特权 API。

当前实机已验证显示、中文字体和鼠标窗口交互；`F1` 可进入通用 Chromium 界面，且 VT 切换未通过，因此本场景尚未完全验收，见[开放调查](../investigations/2026-10-06-kiosk-browser-confinement.md)。

## 边界与失败

- 首次读取失败显示可重试空态；成功后的失败显示失联状态。
- 前台页面每 10 秒刷新，页面隐藏时暂停，重新可见时立即刷新。
- 实时观测超过 30 秒显示过期提示；确定性的 Fake 时间不按实时过期处理。
- 浏览器只访问同源产品接口，不直接访问 Host Agent。
- SSH 隧道是远程开发入口，不是本地控制台运行的前提。
- 桌面只显示浏览器所在设备的系统墙钟，不自行实现网络校时，也不向浏览器或 Host Agent 暴露改时能力。
