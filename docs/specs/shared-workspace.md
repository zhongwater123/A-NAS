# 共享工作区

状态：draft
更新时间：2026-11-27

## 目标

团队在 NAS 上一起写 HTML 页面，第一个用途是用 HTML 写 PRD。成员在浏览器里看页面、指出要改的地方，再让自己电脑上的编码 agent（Claude Code、Codex）去改；能看到共享工作区的人看到的是同一份页面和它的全部版本。

共享工作区是一个功能模块，由管理员决定哪些成员能看到；看得到的人能用其中的全部功能。第一个功能是共享页面。这一版是第一步（里程碑 M1）：上传、隔离浏览、选中元素、agent 修改、版本与导出。

## 非目标

- 批注（留言、圈画、回复）、两版对比、恢复到旧版本：第二步（M2）。
- 在网页里改源码、所见即所得地改文字。页面由 agent 改，或者整份重新上传。
- 一个条目带多个文件或附件；页面引用外网资源（脚本、样式、字体、图片）。
- 多人实时协同（看到对方的光标、逐字同步）。
- NAS 上的 VNAS 使用这些工具，agent 让桌面截图检查自己的修改。
- 用浏览器点“允许”的授权（OAuth）：局域网入口是明文 HTTP，Claude Code 拒绝在上面走 OAuth（[ADR 0040](../adr/0040-let-members-agents-edit-shared-pages-through-agent-tokens.md)）。
- 按页面设置谁能看、谁能改。

## 本稿补充的默认规则

以下是让实现和验收可以执行的设计建议，PR 里逐条列出，可以单独改。

### 谁能用

- 管理员始终能用。成员默认不能用，管理员在共享工作区窗口的“成员”里逐个勾选。
- 能用的人都能上传、浏览、修改、导出任何页面；删除页面，以及从回收站恢复或彻底删除它，只有上传它的人和管理员。

### 页面与版本

- 上传的是一个 `.html` 或 `.htm` 文件，按 UTF-8 读，不超过 20 MB。标题取页面的 `<title>`，没有时取文件名；标题可以改，最多 200 个字。
- 每次保存都是一个新版本，完整保存这一版的内容；版本号从 1 起递增。每个版本记下谁保存的、经什么保存（网页上传，或者某个 agent 的名字）和一句说明。agent 保存时说明写成员对它说的原话，例如“把按钮改小”。
- 删除页面先确认，页面连同全部版本移到回收站：列表里没有了，所有人都打不开，agent 也读不到；窗口提示“已删除“标题””，点“撤销”立即放回。
- 回收站在窗口顶部，能用共享工作区的人都看得到，每一项写谁删的、多久以前、几个版本、几天后彻底删除。上传者与管理员可以“恢复”（连同全部版本放回列表原来的位置）或“彻底删除”（再确认一次）。在回收站满 30 天的页面由服务彻底删除，删除它的人在自己的活动记录里看到。
- 删除的页面也在桌面的“回收站”窗口里，和删除的文件放在一起，所以找删掉的东西只去一个地方：每人看到自己上传的、或自己删除的页面（这些都是他能恢复的），位置写“共享工作区”与版本数，大小是全部版本的合计。在那里“恢复”放回共享工作区，“永久删除”连同全部版本彻底删除，与在共享工作区窗口里操作相同；“清空回收站”也包括这些页面。共享工作区窗口自己的“回收站”仍列出全部删除的页面，打开时每 10 秒重新读一次。
- 服务每天把整个共享工作区的数据库压缩备份一份，留最近 14 份，放在数据卷上共享工作区自己的子卷里，界面上不显示。它防的是数据库损坏和版本、回收站都挽回不了的误操作，不防硬盘损坏；恢复由管理员按[运行手册](../runbooks/restore-workspace-database.md)做。数据卷到了预留空间时这一天不备份，有空间后补上。
- 导出得到所选版本的原文件，文件名是“标题-v版本号.html”。

### agent 的连接

- 成员在窗口里点“连接 agent”，给这个 agent 起个名字（例如“办公电脑”），选 Claude Code 或 Codex，得到一行命令。命令里的地址是浏览器当前打开桌面用的地址，令牌只显示这一次。
- 一个 agent 一个令牌，每个账号最多 20 个。令牌只能用于共享工作区，碰不到 NAS 的其他功能。
- “设置 → 我的账号 → 已连接的 agent”列出名字、种类、上次使用时间，可以撤销。90 天没用过的令牌自动失效。
- 令牌在这些时候不能再用：成员撤销它；管理员停用这个账号或重置它的密码（令牌一并删除，重新启用或改密后也不会恢复）；账号被删除；管理员把这个成员从“成员”里去掉（去掉期间调用被拒绝）。
- 地址只能是 IP 地址或 `localhost`，与终端、Docker 的写操作相同（防 DNS 重绑定）；按主机名打开桌面时，命令里换成 NAS 的 IP。

### 窗口与页面的标签页

- 共享工作区窗口列出全部页面：标题、最后谁经什么保存、版本号、时间，最近保存的在前。窗口顶部是“连接 agent”、“成员”（管理员）、“回收站”和“上传页面”。
- 点一个页面，在浏览器的新标签页里打开它；页面占满整个标签页，不嵌在窗口里。标签页顶部一条窄栏：标题、版本、选取、导出。再点同一个页面回到它已经开着的标签页。
- 改名、上传新版本、导出最新版本、删除在窗口里每一行的“…”菜单中。
- 上传新页面后窗口提示“已上传“标题””，点“打开”在新标签页里打开。
- 本机屏幕上的标签页没有浏览器的标签栏，窄栏里多一个“关闭”，关掉回到桌面。屏保与息屏照桌面的设置；在页面里点按、触摸、按键与触摸滚动算作在用，只滚鼠标滚轮或移动鼠标不算，页面自己的脚本也不能让屏幕一直亮着。
- 没有登录时打开页面的地址，标签页请成员先登录桌面，给出“打开桌面”和“重新载入”。

### 实时与选中

- 开着的页面每 3 秒查一次有没有新版本、谁在看；标签页在后台时不查。
- 自己保存的新版本（自己上传，或者自己的 agent 改的）到来时，页面直接换成新版本，滚到改动的地方并标出“已修改”，几秒后标记淡出。别人保存的新版本只在标签页顶部提示“某某 经 某某 保存了 v5：说明”，点“查看”再换。
- 选中的元素只属于选中它的人，别人看不到，30 分钟后作废；换页面或再选别的元素时替换。
- 成员开着几个页面的标签页时，agent 读到的“这个页面”是成员最后用的那个：最后有焦点的标签页，在一个标签页里选取也算用它。

### 谁在看、谁的 agent 在改

- 页面的标签页窄栏与窗口里这个页面的一行显示还有谁正在看：每人一个头像，悬停显示“正在看：某某”，看的不是最新版本时名字后写版本号。自己不显示。
- “正在看”是这个页面的标签页在前台。标签页切到后台或关闭时立即不算；浏览器没来得及说就关掉的，3 分钟后不算。
- 某个成员的 agent 读了或下载了一个页面，窄栏与这一行显示“某某 经 办公电脑 读了 v3”，窄栏里还写多久以前；这个 agent 保存了这个页面，或 10 分钟没有再读，就不再显示。agent 改一个页面之前先读它，这一条就是谁的 agent 在改。自己的 agent 也显示，可能是自己另一台电脑上的。
- 这些只给能用共享工作区的人看，只在内存里，不记日志，服务重启后清空。
- 不锁页面：几个人同时改由版本处理，见场景“两个 agent 同时改不同的地方”与“两个 agent 改同一处”。

## 场景

### 上传一个新页面

- Given：管理员已把成员 A 加进“成员”，A 的电脑上有 cc 写好的 `prd.html`。
- When：A 打开共享工作区，把文件拖进窗口（或点“上传”选择它）。
- Then：
  - 列表里多一条，标题取页面的 `<title>`，写着“A 上传 · v1”；
  - 窗口提示“已上传”，A 点“打开”，浏览器新开一个标签页，页面占满它，页面里的脚本、样式、动画、画布照常运行；
  - A 的活动记录多一条 `workspace.page_created`。

### 选中按钮，让 agent 改小

- Given：A 已连接 Claude Code，在这个页面的标签页里开着它。
- When：A 点“选取”，点页面里的“发出分享”按钮，再在 Claude Code 里说“把按钮改小”。
- Then：
  - Claude Code 先读 A 正在看的页面与版本、选中元素的源码与行号、作用在它上面的样式规则、尺寸和一张截图，再按原文替换改动的地方；
  - 页面保存为 v2，版本说明是“把按钮改小”，写着“A 经 办公电脑”；
  - A 开着的页面在几秒内换成 v2，滚到按钮处并标出“已修改”；
  - 也在看这个页面的 B 看到顶部提示“A 经 办公电脑 保存了 v2：把按钮改小”。

### 选中一段文字，只说“移除这个”

- Given：A 在 Claude Code 或 Codex 的同一个对话里刚谈过整页上传；A 在页面的标签页里点“选取”，点了一行文字。
- When：A 对 agent 只说“移除这个”。
- Then：agent 第一轮就读 A 的选中，说出要移除的是哪个元素（标签与文字），修改只去掉这个元素，新版本说明是“移除这个”（[#664](https://github.com/zhongwater123/A-NAS/issues/664)）。

### 没有选中时说“移除这个”

- Given：同上，A 随后点“清除选中”。
- When：A 再对 agent 说“移除这个”。
- Then：agent 问 A 要移除哪一项，不按前面的聊天记录推断成删除整页。

### 开着两个页面时说“这个”

- Given：A 在两个标签页里开着页面甲与页面乙。A 在乙里看了一会儿，切回甲，点“选取”选中一个按钮，再切到终端。
- When：A 对 agent 说“把这个改小”。
- Then：agent 读到的是甲和这个按钮；乙在后台说自己还开着，不改变这一点。

### 看到别人在看、别人的 agent 在读

- Given：A 与 B 都能用共享工作区。B 在标签页里开着“家庭相册分享 PRD”，B 的 Codex（“笔记本”）刚读了 v3。
- When：A 打开共享工作区窗口，再打开这个页面。
- Then：
  - 窗口里这一行与 A 的标签页窄栏都有 B 的头像，悬停显示“正在看：B”，还写着“B 经 笔记本 读了 v3”；
  - B 的 agent 保存了 v4 之后，“读了 v3”消失，A 的标签页提示“B 经 笔记本 保存了 v4：…”；
  - B 把标签页切到后台，A 那里 B 的头像在几秒内消失。

### 两个 agent 同时改不同的地方

- Given：A 与 B 都基于 v2 让各自的 agent 修改，A 的改标题，B 的改表格。
- When：A 的 agent 先保存，B 的随后保存。
- Then：A 的修改成为 v3，B 的修改加在 v3 上成为 v4，v4 里两处修改都在；B 的 agent 收到“已在 v3 之上保存”的说明。

### 两个 agent 改同一处

- Given：A 与 B 都基于 v2 让各自的 agent 改同一个按钮的样式。
- When：A 的 agent 先保存为 v3，B 的 agent 再保存。
- Then：B 的这次修改整个不保存，agent 收到“这段原文在最新版本里已经不存在，请重新读取”，重读 v3 后再改。

### 网页上整份上传新版本时页面已被改过

- Given：A 在 v3 时打开页面，随后 B 的 agent 保存了 v4。
- When：A 在窗口里这个页面那一行的菜单中选“上传新版本”，选了一个新文件。
- Then：窗口说明“B 刚保存了 v4”，A 可以取消，或者仍然上传为 v5。

### 连接 Claude Code

- Given：A 能使用共享工作区，电脑上装有 Claude Code。
- When：A 点“连接 agent”，名字填“办公电脑”，选 Claude Code，复制命令到终端运行，再在 Claude Code 里随便问一句共享工作区的事。
- Then：
  - 对话框在 agent 第一次调用后显示“已连接”；
  - “设置 → 我的账号 → 已连接的 agent”出现“办公电脑 · Claude Code · 刚刚使用”。

### 撤销一个 agent

- When：A 在“已连接的 agent”里撤销“办公电脑”。
- Then：这个 agent 之后的调用都被拒绝（`401`），Claude Code 里看到需要重新连接。

### 管理员把成员去掉

- Given：B 能使用共享工作区，并连接了一个 agent。
- When：管理员在“成员”里去掉 B。
- Then：B 的桌面在下次读取时不再显示共享工作区；B 的 agent 调用被拒绝；B 上传过的页面仍在，其他人照常使用。管理员再把 B 加回来时，B 未撤销的令牌又能用。

### 删错了页面

- Given：A 上传了“家庭相册分享 PRD”，有 5 个版本。
- When：A 在这一行的菜单里点“删除…”，确认。
- Then：
  - 确认框写“全部 5 个版本一起移到回收站，所有人都看不到。30 天内可以从回收站恢复。”；
  - 页面从所有人的列表里消失，开着它的标签页写“这个页面已被删除”；
  - A 点提示里的“撤销”，或几天后在“回收站”里点“恢复”，页面连同 5 个版本回到列表原来的位置，A 的活动记录多一条 `workspace.page_restored`。

### 在桌面的回收站里找回页面

- Given：A 上传的“需求文档”有 3 个版本，被管理员删除；A 还删过个人空间里的一份文件。
- When：A 打开桌面的“回收站”。
- Then：
  - 列表里有那份文件，也有“需求文档”，位置写“共享工作区 · 3 个版本”，按“共享工作区”筛选只剩页面；
  - A 点“恢复”，提示“已恢复“需求文档”到 共享工作区”，点提示里的“打开共享工作区”打开窗口，页面连同 3 个版本在列表原来的位置；
  - 别人上传、别人删除的页面不在 A 的回收站里，在共享工作区窗口的“回收站”里能看到。

### 回收站里的页面到期

- Given：B 在 30 天前删除了“旧方案”，没有人恢复。
- When：服务做每 10 分钟一次的清理。
- Then：“旧方案”与它的全部版本彻底删除，从回收站消失；B 的活动记录写“删除的共享页面在回收站满 30 天，已彻底删除”。

### 数据库坏了

- Given：数据卷上的 `workspace.db` 损坏，服务打不开它。
- When：管理员按[运行手册](../runbooks/restore-workspace-database.md)换回前一天的备份。
- Then：共享工作区回到前一天的页面、版本与回收站；那之后保存的内容没有了，成员的 agent 令牌照常可用。

### 导出旧版本

- When：A 在页面标签页的版本菜单里选 v1，点“导出”。
- Then：浏览器下载 `标题-v1.html`，内容与当初上传的文件逐字节相同。

### 页面引用了外网资源

- Given：页面里有 `<link>` 引用 CDN 上的样式，和一张外网图片。
- When：A 打开这个页面。
- Then：这两项都不加载，标签页顶部写“2 项外网资源未加载”，展开后列出地址。页面其余部分照常显示。

### 页面脚本因为隔离出错

- Given：页面的脚本读 `localStorage`。
- When：A 打开这个页面。
- Then：这一段脚本报错停下，标签页顶部写“页面脚本出错：…”；页面其余部分照常显示。

## 边界与失败

- **隔离**：页面在它自己标签页里的隔离框架中运行，来源是不透明的：它读不到 Cookie 和 `localStorage`，访问不了桌面和 NAS 的接口，不能联网，不能打开新窗口、提交表单或让整个标签页跳转。即使页面设法发出请求，请求也不带登录状态。直接打开页面的地址时同样隔离。导出与下载的文件以附件返回，同样带隔离的响应头，不会在桌面的来源里运行。
- **页面伪造选中**：页面里的脚本能冒充“选中”的消息，桌面分辨不出。后果只是 agent 读到页面作者编的上下文；页面内容与选中的文字对 agent 来说都是数据，不是指令，MCP 的说明里写明这一点。
- **修改规则**：agent 每次修改给出若干处“原文 → 新文”，作用在最新版本上；每处原文在最新版本里必须恰好出现一次，有一处不满足就整次不保存，结果说明是哪一处、为什么。整份上传要求基于最新版本，否则拒绝并给出最新版本号（网页上可以确认后仍然上传）。
- **agent 的读取**：读源码按段返回，每段不超过 4 万字符，并说明下一段从哪一行开始；内嵌的大段 base64 数据折叠成占位符，含占位符的原文不能用于修改。整份下载或上传走 10 分钟内只能用一次的地址，agent 用 `curl.exe` 传文件，内容不经过对话。
- **限额**：页面 20 MB；标题 200 字；版本说明 500 字；一次修改最多 50 处；agent 的一次请求不超过 4 MiB（更大的改动走整份上传）。超出时返回 `413 request_too_large` 或 `422 validation_failed`。
- **令牌错误**：令牌不对、已撤销或失效时返回 `401 authentication_required`；同一客户端连续失败按登录失败的方式等待，返回 `429 too_many_attempts` 与 `Retry-After`。带 `Origin` 头的请求（来自浏览器）一律拒绝。
- **看不到共享工作区的人**：`GET /api/v1/workspace` 返回 `404`，桌面不显示图标；其余接口返回 `403 workspace_forbidden`。窗口或页面标签页开着时被移出的成员，下一次读页面或列表时窗口与标签页清空，只显示“管理员没有让你使用共享工作区”和“重试”；桌面图标在页面下次回到前台时消失。
- **服务或数据卷不可用**：接口返回 `503 workspace_unavailable`，窗口写“共享工作区暂时不可用（数据盘未就绪），请稍后再试”和“重试”。不在系统盘暂存。agent 收到同样的说明。
- **活动记录**：上传、保存新版本、改名、删除页面（移到回收站）、从回收站恢复、彻底删除、在回收站到期，以及管理员改“成员”，分别记为 `workspace.page_created`、`workspace.page_saved`、`workspace.page_renamed`、`workspace.page_deleted`、`workspace.page_restored`、`workspace.page_purged`、`workspace.page_expired`（记在删除它的人名下）、`workspace.member_added`、`workspace.member_removed`，归入[日志](logs.md)的“共享工作区”类别，只给操作者本人看。创建、撤销 agent 令牌记为 `user.agent_token_created`、`user.agent_token_revoked`。
- **账号删除**：被删账号从“成员”里去掉，它的令牌随账号删除；它上传和保存的页面与版本保留，显示删除时的名字（[重新启用与删除账号](account-enable-and-delete.md)）。
- **退回旧版本**：退回没有共享工作区的版本时，旧版本删除 agent 令牌表，成员升级后要重新连接 agent；页面数据留在数据卷上共享工作区自己的子卷里，再升级后照常可用。退回没有回收站的版本时，回收站里的页面回到列表，不会因此丢失。
- **备份失败**：备份写不成（空间不够、数据卷只读）时这一天没有备份，服务日志写原因，10 分钟后再试；页面照常可用。备份读的是数据库自己的一个只读连接，备份期间页面照常打开与保存。
- **codex**：连接命令按 codex 源码中的 `codex mcp add --url … --bearer-token-env-var …` 写成，尚未用 codex 实测。

## 验收证据

- 走通整条链路的测试（Go）：经共享工作区服务真实的认证与产品服务的 agent 姿态，上传页面 → 上报选中 → MCP 读到选中元素的源码与行号 → MCP 修改 → 新版本可读、改动位置正确。
- 跨进程接缝两边共用的样例：源码位置的样例页与注入结果（Go 与 Vitest 都读）；桌面与隔离框架之间的消息样例（框架两侧的 Vitest 都读）；agent 令牌的解析经同一份测试数据库。
- 接口契约测试走遍全部操作，含 `401`、`403 workspace_forbidden`、`409`、`413`、`422`、`503`，以及删除、回收站、恢复与彻底删除。
- 存取测试：移到回收站的页面在列表、读取、改名、保存、agent 的工具里都找不到；恢复带回全部版本；30 天后清理；每天的备份能解压、打开，含页面与回收站，留 14 份，空间不够时不留半份文件；断电留下的未压缩副本与半份压缩文件在下一次备份前删除；停服务时压缩随即停下，不留半份文件。
- 桌面回收站的测试：列出自己上传或删除的页面、不列别人的；按“共享工作区”筛选；恢复与打开共享工作区；永久删除前说明版本一起删除；页面读不到时仍列出文件并说明。
- 系统测试：服务的身份、子卷与套接字权限、没有网络、只读重挂后不可用再恢复、回滚与再升级、账号删除等到它回答；agent 令牌经产品服务到达共享工作区服务。
- 浏览器检查（Fake 预览，无头 Chrome）：越权尝试页、选中定位、截图与真实画面一致、新版本到来时滚到改动处。
