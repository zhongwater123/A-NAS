# 成员文件分享

状态：implemented（开发分支；产品规则已确认，尚未部署）
更新时间：2026-10-15

## 目标

同一台 NAS 的成员可以把自己可读的普通文件分享给指定成员。接收者从桌面通知或常驻列表打开分享，预览、选择保存位置，并与分享者围绕这次分享私聊。

## 已确认的产品规则

- 分享支持普通文件、多选和文件夹，可一次选择多名有效成员；成员可以分享自己只有读取权限的共享文件。
- 分享保留发送时的独立内容副本，正式发出后不受原文件修改、移动、删除或分享者退出登录影响。
- 分享副本准备完成、正式发出后有效 7 天；准备期间不计入有效期。
- 在线接收小通知，离线后下次登录补收；“收到的分享”和“我发出的分享”提供常驻入口。关闭通知不等于拒收或删除分享。
- 接收者可以浏览分享中的文件夹、使用现有文件预览能力，并只保存部分内容。不支持预览的格式显示文件信息。
- 保存目标为接收者有写权限的 NAS 个人空间或共享文件夹。同名时自动改名保留两份，保存后副本归接收者独立管理并继承目标位置权限。
- 保存显示进度，关闭分享窗口不停止任务；失败显示原因。
- 分享者可附初始留言，双方可连续对话并使用表情。多名接收者分别与分享者私聊，互相看不到其他人的回复。
- 新回复有小通知和未读标记；正在查看对应讨论时更新消息，不重复弹窗。
- 分享者可以看到每位接收者是否查看、是否曾成功保存，但看不到保存目标路径。消息已读、分享已查看和文件已保存分别记录。
- 分享者可撤回分享。撤回立即停止正在运行的保存任务；自然到期允许到期前已开始的保存任务继续完成，但不再接受新保存任务。两种情况均停止预览和回复，保留分享记录、文件名称清单和历史消息；临时分享副本在不再被允许继续的任务使用后清理，已经保存或下载的内容无法收回。

## 本稿补充的默认规则

以下是使实现和验收可执行的设计建议，并非额外的用户承诺。

- 表情采用消息内的标准 Unicode emoji，支持键盘输入、粘贴和界面表情选择器；第一版不增加图片表情包或消息下的表情回应。
- 初始留言可省略；填写时作为每个私聊的首条消息，后续回复只进入选定接收者的讨论。
- 发出后不能增加接收者、替换内容或延长有效期；需要补充内容时创建新的分享。撤回作用于本次分享的全部接收者。
- 接收者只能看到自己对应的分享记录与讨论，不展示其他接收者身份；管理员角色本身不获得查看内容或私聊的权限。
- 消息只支持文本、换行和 emoji，按纯文本渲染。第一版不提供消息编辑、撤回、附件、群聊或 @成员。
- “已查看”在成功打开分享详情时记录；只有通知送达、关闭通知或后台预取不计为查看。已读游标只推进到实际展示过的消息。
- “已保存”表示至少一个文件或空目录已完整保存，同时展示已确认保存过的不同文件数量，避免部分保存被理解为全部保存；不追踪这些副本后来是否被删除。断连或重启导致提交结果无法确认时，明确显示“保存结果待确认”，不将已确认数量当作完整总数。
- 同一文件夹及其后代同时被选中时去重，保留目录结构和空文件夹。准备失败的分享不通知接收者，也不发布不完整的内容。
- 已发布内容不跟随源文件变化；准备阶段不承诺多个源文件在同一个时刻的事务快照。检测到复制期间内容或目录结构变化时使准备失败，提示停止修改后重试；具体捕获机制须验证不会把单文件混合版本当作成功副本。
- 到期时间以服务端为准，不因读取、回复或保存而延期。“已开始保存”以服务端在到期前完成授权并创建保存任务为准，选取范围与目标位置随任务固定；仅在浏览器点击、请求尚未被服务端接受不算开始。到期后只有这些任务能继续读取所需分享副本，不能借此新增任务、扩大选取范围或开启预览。
- 自然到期停止仍在运行的预览流，但允许已开始的保存任务完成整个选取范围。清理等待所有获准继续的保存任务完成、失败或取消，不在到期时删除它们仍需使用的内容。
- 撤回立即停止预览流和全部未完成的保存任务，包括自然到期后仍在继续的任务；撤回后不得再提交目标文件。已提交的完整目标文件保留，未提交的临时内容清理，任务显示已完成部分与停止原因。不能追回已发送到客户端的字节。
- 刷新或关闭浏览器不丢失记录和消息。后台任务仍需遵循账号和会话授权；会话失效或账号禁用时停止相关操作，重新登录后允许重试，不缓存发送者会话供接收者使用。
- 重复点击或请求重试不重复创建同一分享、消息或保存任务。服务重启后未完成任务标记中断；只有分享仍有效时才允许重新发起保存，已经到期或撤回时不允许重新保存。第一版不承诺跨重启续传；幂等重试可以返回已有任务的状态，不得重启已经终止的任务。
- 账号被禁用后不能访问或发送消息；分享者被禁用时关闭其尚有效的分享，其他有效成员仍能查看自己的历史记录。删除账号引起的内容回收需要与账号删除流程一并实现。

## 场景

### 分享只读共享文件给多名成员

- Given：甲对共享目录只有读取权限，乙、丙是有效成员。
- When：甲选中其中一个文件夹与一个普通文件，选择乙、丙并填写留言后发送。
- Then：甲能看到准备进度；全部准备成功后发布一份固定内容，乙、丙各收到独立分享记录和相同的初始留言，有效期从发布时起计算。
- Then：甲修改或删除原文件、退出登录，不改变已发布内容，也不影响乙、丙在有效期内访问。

### 离线补收与私聊

- Given：乙在线，丙离线。
- When：分享正式发出，随后乙回复含有中文、换行和 emoji 的消息。
- Then：乙收到桌面小通知，丙下次登录能找到未读分享；甲收到乙的回复提醒，丙无法获取乙的讨论或已读状态。
- Then：甲打开与乙的讨论继续回复；多窗口或多设备刷新后消息顺序、未读状态一致，请求重试不产生重复消息。

### 预览和选择位置保存

- Given：乙有一份有效分享，目标文件夹中存在同名文件。
- When：乙浏览内容、预览其中的图片，并选取部分文件保存。
- Then：目标选择器只提供乙有写权限的位置；实际写入时再次检查权限。同名文件自动改名，新文件不修改或覆盖已有内容。
- Then：任务在 NAS 执行，关闭分享窗口后继续；甲能看到乙成功保存过的数量，但不能看到目标目录。

### 自然到期

- Given：乙在到期前已经开始保存一个文件夹，其中部分文件尚未完成。
- When：达到正式发送时间后 7 天。
- Then：双方仍可查看历史记录与消息，不能再预览、发起新保存或回复；原保存任务继续完成所选文件夹，包括任务中尚未开始复制的文件。
- Then：分享副本保留到所有获准继续的任务结束后再清理；其他请求不能通过旧地址或尚未清理的副本绕过失效规则。

### 手动撤回

- Given：乙正在保存分享内容，分享仍有效，或已自然到期但保存任务获准继续。
- When：甲撤回分享。
- Then：预览流与未完成的保存任务立即停止，不再提交目标文件；已保存的完整文件保留，未完成内容清理，任务显示已完成部分与撤回原因。
- Then：双方仍可查看历史记录与消息，不能再预览、保存或回复。

## 技术边界

本节规定新实现必须满足的约束，不改变当前已接受的架构决策。

- 分享记录、每个接收者的私聊、消息和未读游标、保存任务分别建模。文件内容可以由同次分享的多个接收者共用，讨论和用户状态不能共用。
- 分享元数据持久化后才发送通知；通知是提醒，不是唯一记录。实时连接断开后通过持久记录和游标补齐，不依赖某次推送恰好送达。
- 所有条目使用稳定资源 ID，接口不接受任意宿主机路径。目录遍历、预览、缩略图、媒体流、消息和新建保存任务接口都检查当前会话、参与者身份与有效期。到期前已授权的保存任务只能在原任务范围内继续读取，并继续遵守会话、账号、目标权限与撤回检查。
- 原文件经文件代理以分享者身份读取；目标文件经文件代理以接收者身份创建。复制不把源文件 ACL 或属主带进目标目录。
- 现有文件代理自行校验会话，不能用产品服务声明的用户 ID 冒充离线分享者；独立副本的后续访问不得依赖分享者会话继续有效。
- 分享内容只存于身份校验通过的数据卷，不放在系统盘，不通过 SMB 发布；数据卷离线、只读或空间不足时拒绝相应写入，保留明确的失败记录。
- 保存先写隐藏临时内容，完整后再发布为正式文件；任务失败、重启、撤回和到期均需要可重复执行的清理。自然到期时，任务对分享副本的有效引用阻止提前清理；任务创建与到期判定、撤回与目标文件提交必须有确定的先后顺序，不能因并发产生越权任务或在撤回后提交文件。清理记录保留到确认实际内容已删除，卷离线时延期清理。
- 固定副本需要防止分享者、接收者或 SMB 在发布后改写内容。不能仅靠隐藏目录或前端禁用编辑实现不可变性。
- 原文件仅有读取权限即允许分享；管理员查看模式的临时只读访问不自动取得转分享权限。
- 数据传输、预览处理、长任务的并发和消息大小均须有服务端上限；实现设计应给出具体限制及用户可见的超限行为。

### 权限实现的候选方向

当前 [ADR 0008](../adr/0008-use-unified-linux-identities-and-filesystem-acls.md) 规定普通文件仅由文件系统 ACL 授权。临时分享副本跨越成员隔离边界，需要在实现前明确下列两种方向的取舍并形成评审后的架构决定：

| 方向 | 如何隔离 | 需要验证的主要代价 |
|---|---|---|
| 文件代理管理独立分享容器 | 分享容器使用 ACL 授予指定成员读取权限，已发布内容只读；不修改原个人空间 ACL | 多成员 ACL、不可变发布、过期撤权、已打开描述符与清理的协调；需扩展现有根目录授权粒度 |
| 独立分享服务持有受管副本 | 类似相册服务，只持有分享副本，自行确认会话并按分享记录授权；不取得个人空间读取权限 | 新增服务及 Catalog 授权例外，需要 ADR 明确其权限、源内容导入、持久状态和恢复边界 |

无论采用哪种方向，均不能给产品服务或 root 处理逻辑增加任意读取成员源文件的便利接口。现有预览组件可复用，但内容地址与授权不能直接沿用原文件 ID。

## 非目标

- 跨 NAS 分享、外链、匿名访问和浏览器间直接传输。
- 相册中的受管照片资产分享、实时协作编辑、同步文件夹和原文件单文件 ACL 编辑。
- 群聊、独立于分享存在的聊天应用、聊天附件和自定义图片表情包。
- 追回已经保存或下载的副本、自动给已保存内容同步更新。
- 本次不扩展传输中心范围；NAS 内部保存任务在分享详情中显示，浏览器下载可作为后续独立入口设计。

## 验收证据

本功能尚未实现，以下为实现时必须提供的验证证据，不表示测试已经通过：

- Fake 与真实权限环境覆盖：只读源可分享、他人不能越权预览或读私聊、管理员无隐式权限、目标只读拒写、到期访问拒绝。
- 真实文件系统验证：原文件修改和删除不影响已发布副本、复制期间源文件变化、空目录、多选去重、同名竞争、临时文件不可见、目标继承权限。
- 带可控时钟的测试覆盖：发布后满 7 天失效、回复不续期、到期前已创建的保存任务完成全部选取范围、到期后新任务拒绝、任务创建与到期竞争、到期后的保存仍可撤回、撤回与目标提交竞争、预览流停止、正在保存的副本不被提前清理、延迟清理不开放其他访问、重启后不重建已过期的保存任务。
- API 与界面验证：发送幂等、消息重试去重、离线补收、连续回复与组合 emoji、多接收者私聊隔离、多设备已读游标及部分保存状态。
- 故障恢复覆盖：准备失败、卷离线、空间不足、会话过期、账号禁用、服务重启和清理重试。
- 文档变更运行 `make docs-check`；实现与跨模块契约变更运行 `make check`，权限实现另需在可丢弃环境完成 root 集成测试。
