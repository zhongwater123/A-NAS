# 系统快捷栏

状态：implemented
更新时间：2026-10-10

## 目标

桌面左侧的系统快捷栏只放可用的系统级操作：回到桌面、找到并打开任意应用、进入设置、管理当前账号。每个按钮都能看出用途和当前状态，退出登录不会被误点触发。

## 非目标

- 不新增或修改产品 API。账号通知仍是登录后弹出的确认框，服务端只返回未确认的通知，快捷栏不提供通知历史。
- 不放“规划中”的占位按钮。规划中的应用只出现在桌面图标和启动器的“规划中”分组。
- 不注册全局键盘快捷键。Kiosk 中 Chromium 保留的组合键尚未收敛，见[开放调查](../investigations/2026-10-06-kiosk-browser-confinement.md)。
- 不提供锁定屏幕；本机屏幕的闲置行为见[屏幕保护程序](local-console-screensaver.md)。

## 结构

从上到下依次是“显示桌面”和“全部应用”，再隔开一段是“设置”和账号头像。快捷栏与状态栏、程序坞使用同一种深色玻璃。按钮只显示图标，悬停约 0.3 秒或用键盘聚焦时在右侧显示名称提示。左边缘的白色标记表示用户当前所在的位置：看到桌面时标在“显示桌面”，“设置”窗口在最前时标在齿轮。弹出面板打开时，对应按钮显示为按下。

窗口宽度不超过 620 px 时，快捷栏改为屏幕底部的横条，四个按钮全部保留：位置标记移到按钮下沿，不显示名称提示，启动器和账号菜单从横条上方弹出。

## 场景

### 显示桌面并恢复窗口

- Given：有应用窗口显示在桌面上。
- When：点击“显示桌面”，之后再点一次。
- Then：第一次点击把所有窗口最小化到程序坞，按钮变为按下状态，名称提示变为“恢复窗口”。第二次点击只恢复刚才被它隐藏的窗口，层叠顺序和焦点窗口不变；之前手动最小化的窗口保持最小化。如果在两次点击之间打开或恢复了窗口，下一次点击按第一次处理。没有可显示的窗口时，按钮保持按下且点击无反应。

### 从启动器搜索并打开应用

- Given：桌面已打开，可能有窗口遮住桌面图标。
- When：点击“全部应用”。
- Then：快捷栏右侧弹出“全部应用”面板，光标落在搜索框中。面板按用户在桌面上排好的顺序列出当前账号可用的应用，正在运行的应用图标下有圆点；规划中的应用单独列成不可点击的小标签。输入文字后按应用名称和用途关键词筛选，比如“命令行”找到终端、“容器”找到 Docker、“密码”找到设置，第一个结果高亮，按 Enter 打开。方向键在搜索框和应用之间移动，上下方向键按网格换行，从第一行向上回到搜索框。没有匹配时提示没有该名称的应用。打开应用后面板关闭。

### 账号菜单与退出登录

- Given：任一角色已登录桌面。
- When：点击快捷栏底部的头像。
- Then：弹出账号菜单，显示账号名、角色（管理员或成员）和本次登录：本机屏幕会话显示“退出前保持登录”，浏览器会话显示 12 小时有效期的截止时间。菜单项为“我的账号”（进入[设置](settings.md)的“我的账号”）和“退出登录”，打开时焦点在第一项，上下方向键切换。退出登录只能在菜单中完成，快捷栏上没有一键退出按钮。

### 关闭弹出面板

- Given：启动器或账号菜单已打开。
- When：按 Esc、在面板和触发按钮之外按下指针、用 Tab 把焦点移出面板，或再次点击触发按钮。
- Then：面板关闭。按 Esc 关闭时焦点回到触发按钮；同一时间只打开一个面板。

## 边界与失败

- 快捷栏不读取额外数据：应用列表与桌面图标共用同一份定义，管理员才可见的终端、应用中心与 Docker 在成员的启动器中同样不出现。
- 启动器读取桌面图标顺序（`localStorage` 键 `a-nas.desktop-order.v1`），但不修改它；读取失败时使用默认顺序。
- 会话类型由服务端返回的过期时间判断：本机屏幕会话的过期时间固定为 9999 年，见[会话处理调查](../investigations/2026-10-09-local-console-disconnected-after-session-expiry.md)。
- 启动器与账号菜单显示在窗口之上、程序坞之下；系统偏好减少动态效果时取消弹出动画和按钮过渡。

## 验收证据

- React 行为测试：[桌面测试](../../web/src/App.test.tsx) 覆盖快捷栏只含可用按钮、显示桌面与只恢复被隐藏的窗口、按关键词搜索并用 Enter 打开、Esc 关闭并归还焦点、只能从账号菜单退出登录；[快捷栏测试](../../web/src/SystemRail.test.ts) 覆盖会话说明。
- 浏览器检查：Fake 模式预览中在 1024×680 与 390×760 下检查快捷栏、名称提示、启动器的方向键导航，以及启动器与账号菜单在窗口之上的显示。
