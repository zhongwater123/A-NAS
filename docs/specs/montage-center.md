# 剪辑中心

状态：draft（首版；实施方案 proposed，见[技术设计](../architecture/montage-center.md)）
更新时间：2026-11-17

## 目标

成员把一次旅行或活动拍的一批视频交给剪辑中心，选一首歌、写一句要求，就能得到一条跟着音乐剪好的成片。成片存进本人的个人图库，像其他视频一样播放、下载。

剪辑中心是桌面上与家庭中心、影视中心并列的应用（[#514](https://github.com/zhongwater123/A-NAS/issues/514)）。

## 已确认（2026-11-17）

经过见[决定记录](../decisions/2026-11-17-montage-center-first-version.md)。

- **剪法与配乐**：
  - 剪法用原型第八版；
  - 配乐只用已分析过的 10 首歌，仅供内部测试。
- **数据归属**：
  - 原片和成片都在本人的个人图库里，相册是事实源；
  - 视频的基础分析（窗口向量、卡片、画质、卡片描述）由相册计算并保存，按内容复用；
  - 剪辑中心只保存项目、规划、时间线与任务。
- **规划**：
  - 由成员自己的 VNAS 完成，只发文字描述、不发画面；
  - 描述不抄号码，交给 VNAS 前再替换可能出现的号码；
  - 任务在等规划时，成员打开桌面就自动开始，并在桌面上提示。
- **做不到的要求**：简单提示一下。

## 本稿补充的默认规则

下面的场景里有几项做法是为了能实现和验收而补的建议，不是额外的产品承诺。是否保留见[决定记录](../decisions/2026-11-17-montage-center-default-rules.md)。

## 非目标

- 一次出三版、挑一版、快捷微调；精修（换镜头、拖动、删除、锁定重洗、预览、导出镜头清单）。
- 竖屏、指定时长、多首歌、字幕、保留原声。成片固定为 1920×1080、30 帧，时长跟着音乐段落走。
- 日常或定时剪辑、VNAS 自主剪辑、扫描整个图库。
- 用户上传歌曲、在 NAS 上运行 allin1 分析歌曲。
- 把接连拍的几段原片拼成一条再剪（第八版的拼接工具）：首版每段视频单独处理。
- 断点续传：沿用相册的上传，单个视频最大 4 GiB。
- 活动记录：首版不写。
- RK3588。

## 场景

### 上传一批视频新建项目

- Given：成员 A 打开剪辑中心。
- When：A 拖入一批视频（或一个文件夹），上传完成后选“新建项目”。
- Then：
  - 视频经相册的上传队列存进 A 的个人图库，进度也显示在传输中心；
  - 上传失败的可以重试，或者跳过，只用成功的建项目；
  - 新项目只包含这一批视频，A 的其他视频不会混进来；
  - 相册开始在后台分析这些视频，项目页显示分析进度。

### 从相册选视频

- Given：A 的相册里已有视频。
- When：A 在剪辑中心用相册的选择器选几段 A 能看到的视频，建项目或加入已有项目。
- Then：只有选中的视频进入项目。A 看不到的、在回收站里的、不是视频的，都不能选入。

### 追加素材

- Given：A 的项目已有成片。
- When：A 再上传一批视频，上传完选“加入已有项目”。
- Then：素材追加进项目，已有成片不变，也不会自动重新生成；由 A 决定是否再生成一版。

### 确认素材与配乐

- Given：A 的项目素材已定。
- When：A 进入配乐页。
- Then：
  - 页面显示素材数与总时长；
  - 列出曲库里通过校验的歌，可以试听；
  - 默认选中 A 上次用的歌，第一次用时选第一首。

### 写一句要求并开始

- When：A 写一句要求（最多 200 字），选择是否按拍摄时间排列，点“开始”。
- Then：
  - 生成一个任务，页面显示当前步骤、进度、排队位置；
  - A 可以关掉窗口去做别的，回来时进度从服务端恢复；
  - 要求里出现竖屏、指定时长、两首歌、字幕、原声时，输入框下方提示首版的限制，不拦着继续。

### 规划

- Given：A 的任务分析完成，进入“等待规划”。
- When：A 打开桌面（剪辑中心窗口不必开着）。
- Then：
  - 桌面在 A 的 VNAS 里开始一次规划，A 的助手历史里多一段标题为“剪辑：<项目名> · <时间>”的对话；
  - 桌面提示“正在规划”；
  - VNAS 交回的规划经校验后收下，任务继续往下走。

### 成片存进相册

- When：渲染完成。
- Then：
  - 成片作为一个视频存进 A 的个人图库（名称与拍摄时间按默认规则）；
  - 项目页显示这个版本，桌面提示“成片已存进相册”；
  - 在剪辑中心或相册里都能播放、下载这条成片；
  - 同一个版本重试也只存一次。

### 再生成一版

- When：A 在已有成片的项目里改了歌或要求，再点“开始”。
- Then：
  - 生成新的一版，旧版不覆盖；
  - 没变的分析与规划直接复用，不重新计算；
  - 新版失败时，旧版照常可播。

### 取消

- When：任务进行中，A 点“取消”。
- Then：
  - 任务立即不再往下走，正在进行的渲染停止，规划中的 VNAS 回合被中断；
  - 不会存进相册；
  - 之后 VNAS 交来的答案被拒绝。

### 素材进回收站或被删除

- When：任务执行中，A 把一段素材移进回收站。
- Then：任务暂停，项目页写“有 N 个视频在回收站，恢复后继续”；恢复后自动继续。
- When：A 永久删除了一段素材。
- Then：任务停下，列出缺失的视频，由 A 选“去掉这些继续”或“取消”。已存进相册的成片不受影响。

### VNAS 不可用

- Given：设备上 VNAS 没有密钥，或者 A 的实例起不来。
- When：A 的任务走到规划。
- Then：
  - 任务停在“等待规划”，项目页与桌面提示写明原因；
  - 上传、浏览项目、播放已有成片都照常。

### 规划没有交回

- When：VNAS 的这一轮结束了，规划却没有交齐；或者 30 分钟没有交回。
- Then：
  - 项目页显示“VNAS 没有交回规划，重新规划？”；
  - 只有 A 点了才开下一轮，不会自动再次调用模型。

### 删除项目

- When：A 删除一个项目。
- Then：
  - 项目、版本记录和规划都删除，相册对剪辑中心的授权撤销；
  - 相册里的原片和成片都保留。
  - 确认对话框写明这一点。

### 两名成员互不可见

- Given：成员 A 与 B 各有项目。
- When：B 请求 A 的项目、任务或一轮规划，或者 B 的 VNAS 调用 A 的任务。
- Then：回答“不存在”，不暴露 A 的项目是否存在。

## 边界与失败

- **成员离线后的访问**：剪辑中心不保存会话。成员离线后，它凭相册持有的项目授权读素材、存成片；相册每次按成员当前的权限重新判断。成员账号停用或看不到某段素材时，任务按“缺失”处理。
- **画面不出设备**：画面只交给本机的 FFmpeg 和本地模型。发给云端的只有文字：用户的要求、卡片描述（去掉号码后）、拍摄时间等元数据（[#295](https://github.com/zhongwater123/A-NAS/issues/295)）。
- **助手能看到什么**：助手经相册接口仍看不到视频；经剪辑中心的工具，只能读到本人项目里视频的文字描述。
- **资源**：剪辑分析在相册的 AI 准入里运行，有人在用相册时让路；渲染以低优先级运行，不和正在播放的视频抢 CPU。一组素材的描述在 NAS 上可能要几个小时。
- **存储**：数据卷离线或只读时，剪辑中心整体不可用，不在系统盘建替代目录。空间不足时，生成停在“空间不足”，腾出空间后可重试；已有项目与成片照常可看。
- **重启**：服务重启后任务从没完成的步骤接着做，已经完成的分析与规划不再重做。
- **曲库**：不合格的歌（缺节拍、识别不出副歌、选不出 30–150 秒的段落、最长的槽超过 12 秒）不出现在配乐页，服务日志写明原因。

## 验收证据

证据分五层：
- **单测**：Go 或 Python 单元测试，用替身；
- **契约**：OpenAPI 契约测试；
- **系统测试**：`scripts/system-test.sh`，真实安装和 systemd，用替身模型与替身计算 Worker；
- **开发机**：真实媒体和真实模型；
- **实验 NAS**：真机。

替身只能证明控制流和校验，不能证明模型质量、性能和内存。

### 首版闭环（实验 NAS）

1. 成员 A 在剪辑中心上传品杰一组里的 11 段视频（约 6 分钟），选《Symphony》，点开始。验收：
   - 视频出现在 A 的个人图库；
   - 任务依次经过各步骤，规划由桌面自动发起；
   - 生成一条 1920×1080、30 帧、带音乐的成片，时长等于音乐选段，误差不超过 0.1 秒；
   - 成片出现在 A 的个人图库，可以播放和下载。
2. 生成途中刷新页面、关闭再打开窗口，进度从服务端恢复。
3. 生成途中执行 `systemctl restart anas-montage`：任务立即从没完成的步骤接着做，已经完成的分析与规划不再重做。核对方法：相册描述步骤的 AI Worker 调用次数与规划的回合数都不增加。
4. 记录各步骤的耗时与峰值内存，包括相册的分析。#514 不设门槛，这些数字作为以后性能评估的基线。

### 相册的剪辑分析

| 触发 | 预期 | 证据 |
|---|---|---|
| 两个项目（或两名成员）请求同一个视频 | 只算一次；已有结果时不再排队 | 单测（相册） |
| 没有被授权请求过的视频 | 不排分析任务；迁移与缩略图完成后都不排 | 单测 |
| 47 分钟素材的窗口分析完成 | 窗口数等于各段 ⌈时长 ÷ 2 秒⌉ 之和（品杰一组约 1,460 个）；向量在 Catalog 中，同时同步到 Qdrant | 开发机 |
| Qdrant 实例被清空 | 窗口集合从 Catalog 重写；`analysis` 照常从 Catalog 读 | 单测 |
| 资产被永久删除 | 它的窗口、卡片、画质、描述行与 Qdrant 中的点都删除 | 单测 |
| 授权全部撤销满 7 天 | 这个对象的剪辑分析删除 | 单测 |
| 换模型或改分析身份中的任一项 | 只重排仍被授权引用的对象 | 单测 |
| 相册的搜索、聚合、找相似、AI 整理进度、助手的相册接口 | 仍然不出现视频 | 单测（现有用例保持通过） |
| 分析进行中有人使用相册 | 分析暂停；描述进行中，相册搜索在秒级返回 | 单测（准入），开发机 |
| 描述里出现证件号、车牌一类号码 | 存进 Catalog 前已被替换 | 单测 |
| 卡片描述失败 | 项目页可以“重试分析” | 单测 |

### 媒体与 AI 操作

| 触发 | 预期 | 证据 |
|---|---|---|
| `frames` 请求 1,201 帧，或灰度帧总量超过 64 MiB | 预检回答 `invalid_request`，不启动 FFmpeg | 单测 |
| `frames` 运行中输出超限 | 报错 `too_large`，不截断，不是 `unreadable` | 单测（真实 FFmpeg） |
| `segment` 输入竖拍视频 | 输出 1920×1080，模糊背景，没有黑边 | 开发机（抽帧比对） |
| 各段 `segment` 按顺序首尾相接后交给 `assemble` | 成片可播放；切点处没有花屏；时间戳连续；时长误差 ≤ 0.1 秒 | 开发机 |
| 请求里带路径或 filter 字段 | 被拒绝（未知字段） | 单测 |
| `describe_frames` 收到 21 张图，或不合 Schema 的回答 | 前者 `invalid_request`，后者 `invalid_result` | 单测 |
| 关键帧最多的竖拍卡片（11 张） | 在 8,192 的上下文里描述成功，回答不被截断 | 开发机 |
| 渲染时播放一段需要转码的视频 | 播放不卡顿；渲染进程的 nice 为 10 | 开发机，实验 NAS |

### 规划（VNAS）

| 触发 | 预期 | 证据 |
|---|---|---|
| VNAS 没有密钥或实例起不来 | 任务停在 `waiting(vnas)`，页面与桌面提示说明原因；上传、浏览、播放可用 | 单测，开发机 |
| 两个桌面标签页同时发现任务在等规划 | 只开一轮 | 单测 |
| 同一个 `attemptToken` 交两次 | 第二次回答“已收下”，答案不变 | 单测 |
| 不合 Schema 的答案 | 回答 `rejected`（不是 `isError`）；连续 3 次后 `needs_input(plan_invalid)` | 单测 |
| 这一轮结束了没有交回 | `needs_input(vnas_unknown)`；不自动发起新的一轮 | 单测 |
| 等规划时重启剪辑服务 | 进行中的一轮不重开 | 单测 |
| B 的 VNAS 调用 A 的任务 | 拒绝（对端 UID 不匹配） | 单测 |
| 沙箱外的进程、定时任务单元连剪辑的助手套接字 | 连不上；managed 配置里 `montage` 的 `trust` 是 `full` | 系统测试 |

### 任务与校验

| 触发 | 预期 | 证据 |
|---|---|---|
| 计算 Worker 或 FFmpeg 实例被 kill | 这一步重试，最多 3 次；用完后 `failed`，没有永远卡在 `running` 的任务 | 单测（替身），系统测试 |
| 时间线有空槽、越界、引用外部资产 | `failed`，不渲染 | 单测（回归） |
| 渲染中取消 | FFmpeg 实例结束；不存进相册；任务 `cancelled` | 单测，开发机 |
| 已有版本 1，再生成版本 2 失败 | 版本 1 仍可播放 | 单测 |
| 数据卷只读 | 整体回答 `montage_unavailable`；系统盘上不出现剪辑数据 | 系统测试 |
| 存回相册时空间不足 | `needs_input(storage_full)`；腾出空间后重试，只存一次 | 单测 |
| 输入摘要中任一项变化（例如换歌） | 只重做受影响的步骤及其下游 | 单测 |

### 曲库

| 触发 | 预期 | 证据 |
