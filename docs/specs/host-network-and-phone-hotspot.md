# 宿主机网络与手机直连热点

状态：draft
更新时间：2026-11-23

## 目标

管理员在「设置 → 网络」管理 NAS 的有线和 Wi-Fi 连接。宿主机 NAS 使用网线上网时，管理员可开启直连热点。手机加入热点后用浏览器登录 A-NAS Web 桌面，选择照片、视频或文件并上传。首版范围见[决定记录](../decisions/2026-11-19-host-network-and-phone-hotspot-v1.md)。

## 网络设置

- 显示有线和无线接口、连接状态、地址和当前上网出口。有线支持 DHCP 和手动 IPv4 配置。Wi-Fi 支持扫描、连接、保存和重连。
- 管理员修改可能中断访问的配置时，先试用。通过变更后的连接或本机控制台确认后保存。超时、连接失败或确认前重启时恢复上一份已确认配置。
- 网络变更由 Host Agent 接收经过校验的高层操作。管理员权限在服务端校验。网络密码由宿主机的网络管理组件保存，日志与普通状态读取不返回密码。

## 手机上传

1. 手机无法访问 NAS 所在的局域网时，管理员可在「设置 → 网络」开启直连热点，供附近的手机临时上传。界面显示热点名称、密码和固定 Web 地址 `http://192.168.173.1/`。首批支持空闲的 MT7612U USB 网卡。网卡、依赖、有线出口或网段有问题时，设置页显示原因。
2. 手机加入热点，在 Safari 或 Chrome 打开该地址，用自己的 A-NAS 账号登录。热点不共享 NAS 的互联网出口，手机系统可能提示「无互联网连接」。用户保持连接后仍可访问热点内的 Web 地址。
3. 手机在窄屏 Web 桌面打开文件管理或相册，用系统选择器选择并上传。传输中心显示进度、失败原因和完成状态。上传到普通文件目录或图库时分别沿用现有授权。
4. 手机短暂掉线或切到后台导致上传中断时，回到浏览器并连回同一热点后，按传输中心的规则恢复。浏览器重新载入并释放文件引用时，允许重新选择同一个文件，接回仍存在的上传任务。

## 接入边界

- 热点使用独立无线接口、本地 DHCP 与每次开启时生成的 WPA2 密码。固定网段与已有路由重叠时拒绝启动。热点只开放 Web 桌面所需的入口和地址分配，不桥接或转发到有线局域网。
- 默认由管理员开启和关闭热点。重启 NAS 后热点关闭。开启失败或关闭时清理热点地址和防火墙规则。热点客户端掉线时，NAS 有线出口和现有入口保持可用。管理员接口和 Host Agent 返回连接信息时均禁止缓存。
- 热点先交付。有线和 Wi-Fi 的配置变更按上文另行实施。
- 首版覆盖设备启用后的手机浏览器上传。SMB、SSH、已安装应用的独立端口、无屏首次配网和锁屏后持续后台传输不在首版验收范围内。

## 验收

- 在宿主机 NAS 确认有线出口、无线接口 AP 能力和可用网段。从有线端持续访问 NAS，同时开关热点并验证 NAS 自己能连接互联网服务。
- 用 iPhone Safari 与 Android Chrome 真机验证连接、打开 Web 桌面、登录、选照片和文件。覆盖移动数据保持开启，以及手机提示热点没有互联网时的路径。
- 分别验证单个大视频与多张照片上传。确认触控可完成选择，进度与完成状态可见，上传文件的字节数与内容正确。覆盖临时断开 Wi-Fi、切后台再返回、刷新后重选文件。
- 在手机通过日常网络无法访问 NAS 内网地址的条件下，验证加入热点后能完整上传。若测试环境允许手机经现有 Wi-Fi 访问 NAS，再用同一手机、同一大文件和同一目标目录对比吞吐与上传用时。测速记录同时保留热点频段、客户端型号和距 NAS 的距离。
