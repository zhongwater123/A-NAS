# AI 助手

状态：draft（[ADR 0022](../adr/0022-run-a-sandboxed-hermes-agent-per-member.md) 已在开发机 spike 中验证；对话列表、对话、停止与确认卡片已有在开发机上跑通的原型；待评审）
更新时间：2026-10-15

## 目标

每个成员在桌面的“AI 助手”中拥有自己的智能体：能读本人的文件、共享空间与本人可见的照片，能在自己的助手目录中自由工作；对本人文件和 Agent空间的任何更改都要本人确认，任何情况下都不能破坏他人的数据或越出这些范围。

## 非目标

- 不提供终端、代码执行、浏览器、联网搜索、定时任务与外部消息平台（微信、飞书等）的入口（[ADR 0022](../adr/0022-run-a-sandboxed-hermes-agent-per-member.md) 决定 8）。
- 不写照片、图库、用户标签或 AI 纠错；不读快照。
- 不处理开发期云端 API 的隐私问题：云端 API 只用于开发测试，本地多模态模型接入前不在保存真实家庭数据的设备上为成员开启助手。
- 不让管理员看到或代为确认成员的助手对话、记忆与待确认更改。
- 不提供 Hermes 自带的网页控制台；模型、工具、插件与技能目录的配置不对成员开放（[ADR 0022](../adr/0022-run-a-sandboxed-hermes-agent-per-member.md) 决定 9）。

## 访问范围

| 位置 | 读 | 写 |
|---|---|---|
| 本人的助手目录 | 可以 | 可以，直接写 |
| 本人的个人空间（含本人的回收站条目） | 可以 | 新建、修改、移动、改名、删除，每批经本人确认 |
| 共享空间（含本人的回收站条目） | 可以 | 不可以 |
| `共享空间/Agent空间/<本人>` | 可以 | 同个人空间，每批经本人确认 |
| `共享空间/Agent空间/<其他成员>` | 可以 | 不可以 |
| 本人的私有图库、共享图库 | 可以（列表、元数据、搜索、缩略图） | 不可以 |
| 快照、其他成员的个人空间、私有图库与回收站（包括管理员已获查看授权的） | 不可以 | 不可以 |
| 系统设置、应用、宿主机、局域网与外网 | 不可以 | 不可以 |

## 场景

### 设备未开启助手

- Given：设备的 root 没有在配置中填写模型网关的上游地址与密钥。
- When：成员查看桌面。
- Then：“AI 助手”保持“规划中”的禁用状态，不创建任何实例、目录或套接字。

### 首次打开

- Given：设备已开启助手，成员第一次打开“AI 助手”。
- When：窗口打开。
- Then：Host Agent 为该账号建立助手目录、`共享空间/Agent空间/<账号>` 与实例套接字；之后产品服务经套接字启动该账号的实例。其他成员的实例与目录不受影响，也看不到这个成员的。

### 对话列表

- Given：成员与助手有过多次对话。
- When：打开“AI 助手”。
- Then：侧栏按最近时间列出本人的对话，标题由助手在第一轮后自动生成，可以改名（最多 100 字，本人的对话之间不能重名）和删除；点开一个对话显示完整历史，可以接着聊。新回复逐字出现；一轮中的读文件、搜索、提交更改等动作折叠成一行“处理过程”，进行中显示当前动作，结束后显示动作数，展开可看每一步。数据来自 Hermes 的会话接口，经产品服务转发，只包含本人的对话。

### 停止回答

- Given：助手正在回答。
- When：成员点“停止”，或在回答结束前切到另一个对话。
- Then：Hermes 中断这一轮；已完成的动作留在记录中，回复标为“已停止”，没有英文的内部提示。成员可以接着发下一条。回合不在后台继续，重新打开对话时也不会接上（[ADR 0022](../adr/0022-run-a-sandboxed-hermes-agent-per-member.md) 后果）。

### 查看与清除助手记住的内容

- When：成员打开助手的“记忆”。
- Then：看到助手记住的内容和它自己创建的技能，可以逐条删除或全部清除；清除后的新对话不再带入这些内容。系统附带的技能不在其中，也不能删除。

### 读取与搜索

- Given：成员的助手已启动。
- When：成员让助手查找或总结个人空间、共享空间或 Agent空间中的文件。
- Then：助手用 Hermes 自带的文件工具直接读取与搜索；结果与该成员在文件管理中能看到的一致，不包含其他成员的个人空间、他人的回收站条目与快照。

### 搜索照片

- Given：成员的私有图库与共享图库中有照片。
- When：成员让助手“找去年在海边拍的照片”。
- Then：助手经相册服务的只读工具搜索，返回本人可见的照片资产与缩略图；即使该成员是管理员并持有查看授权，结果也不包含其他成员的私有图库。

### 在助手目录中工作

- When：助手整理笔记、生成报告或保存中间结果。
- Then：文件直接写入助手目录，不需要确认；助手目录写满容量上限时写入失败，助手报告空间不足。

### 修改本人的文件

- Given：成员让助手修改个人空间里的 `计划.md`、删除两个旧文件并新建一个文件夹。
- When：助手把新内容写入助手目录的暂存区，并“提交更改”。
- Then：这一轮停下等待成员的决定，个人空间中的文件此时都没有变化。这个对话中出现一张确认卡片，列出每项操作、修改的差异或新文件预览、删除的文件名，按钮只有“确认”与“拒绝”。卡片只属于发起它的对话（[ADR 0022](../adr/0022-run-a-sandboxed-hermes-agent-per-member.md) 决定 4）。

### 卡片只在发起它的对话中

- Given：助手在一个对话中等待确认。
- When：成员打开另一个对话。
- Then：那个对话中没有这张卡片，也没有汇总所有待确认更改的列表。这一轮仍在进行时（见“停止回答”），侧栏中发起它的对话带“等你确认”的标记，回到这个对话时卡片仍在。

### 本人确认

- Given：确认卡片还在等待。
- When：成员在自己的登录会话中点“确认”。
- Then：文件代理以成员本人身份按顺序执行卡片中显示的内容；删除的文件与被覆盖的旧版本进入本人的回收站，可以从回收站恢复。活动记录写“由助手提议，本人确认”。卡片变为“已执行”，助手在同一轮中收到结果并据此回答。

### 拒绝、超时与停止

- When：成员点“拒绝”，或在等待时限（`approvals.timeout`）内没有回答，或停止这一轮。
- Then：什么都不改变，卡片分别标为“已拒绝”“已过期”“已停止”，不再能确认；助手在同一轮中得知用户没有同意，不换个方式再提交，除非成员再次要求。时限过后再点确认无效。

### 卡片之后的变化

- When：卡片出现后，助手又改写了暂存区中的同一份草稿，或目标文件被改动（例如成员自己在文件管理中编辑了它）。
- Then：确认后写入的仍是卡片中显示的内容，之后对草稿的改写不会被写入；目标已被改动时不执行，卡片提示“文件已变化，请让助手重新提交”。同一张卡片只能执行一次。

### 部分失败

- Given：一批操作执行到中途时目标空间写满或数据卷离线。
- Then：执行停在失败的一项，卡片列出已执行与未执行的操作，助手收到同样的结果；已执行的删除与覆盖仍可从回收站恢复，不自动回滚。

### 写入不允许的位置

- When：助手提交的更改指向共享空间中 `Agent空间/<本人>` 以外的位置、其他成员的子目录，或来源不是暂存区中的文件。
- Then：不出现确认卡片，助手收到原因；即使绕过提交，执行进程也会被 Landlock 拒绝。

### 只有本人能确认

- When：管理员的会话、其他成员的会话或助手自己的通道尝试确认某成员的待确认更改，或 Hermes 在没有本人点击的情况下应答“同意”。
- Then：请求被拒绝，更改不执行；助手在对话里声称“用户已同意”不产生任何效果。

## 边界与失败

- 实例只看得到三处挂载：个人空间（只读）、共享空间（只读）、助手目录（读写）；没有网络，只经 Unix 套接字访问产品服务的模型网关与 MCP 端点。
- 实例以本人 Linux 身份运行，附加组只有 `a-nas-users`；看不到实例外的进程，不能 ptrace，没有任何能力。两处空间的回收站在实例中只显示本人的文件夹。
- 助手在每个对话中都知道它代表哪位成员、目录规则与暂存流程（随系统提供的技能），不需要先探索。
- 模型网关不可用时，助手报告“模型暂不可用”；文件、相册与其他功能不受影响（[架构不变量](../architecture/OVERVIEW.md#不变量) 1）。
- 窗口只显示中文的失败说明，按错误码选择（实例无响应、正忙、对话不存在、重名、更改已处理等）；Hermes 与模型服务商的英文错误只留在日志中。
- 数据卷离线时助手不可用，不回退到系统盘；实例崩溃时由下一次请求重新启动，进行中的确认随这一轮作废。
- 实例在最后一次请求 10 分钟后退出，下次打开时冷启动（开发机 5.5–11 秒，窗口显示“助手正在启动”）；同一成员同时打开多个窗口时共用一个实例。
- 实例内存上限 768 MiB，超过 640 MiB 时内核先回收（开发机用真实模型多轮对话后常驻约 375 MB、峰值不超过 442 MB）；任务数上限 256。
- 助手目录写满容量上限时写入失败；容量上限与确认的等待时限（spike 用 Hermes 默认的 300 秒）尚未确定。

## 验收证据

- 系统测试在真实单元中运行沙箱探针：实例读不到其他成员的个人空间与快照，写不进个人空间与共享空间，打不开外网连接，看不到实例外的进程（开发机 spike 的 22 项探针见[研究](../research/hermes-agent-runtime.md#spike-结果2026-10-14开发机)第 5 项与 [`probe.sh`](../../ai/assistant-spike/probe.sh)，正式实现移入系统测试）。
- 执行进程的 Landlock 测试：对个人空间与 `Agent空间/<本人>` 之外的写入返回拒绝。
- 工具收窄测试：模型只被提供文件、记忆、技能与 A-NAS 的工具；在助手可写的 Hermes 配置中启用终端后重启，终端仍不可用（spike 第 3 项）。
- 边界测试：Hermes 启动时加载的配置、`.env`、`SOUL.md`、钩子与插件在实例中只读；越界与经符号链接的提交被拒绝；真实模型面对“授权跳过确认”、写他人与共享根目录、索要密钥以及共享空间中的诱导文字时，不越界、不执行诱导，记忆中不留下诱导内容（[研究](../research/hermes-agent-runtime.md#边界测试2026-10-14开发机)）。
- 产品服务测试：越界提交不出卡片；非本人会话与助手通道的确认被拒绝；Hermes 未经本人点击的“同意”不执行；时限过后或停止后的确认无效；参数与卡片不一致时不执行；卡片之后改写的暂存内容不被写入，目标变化后不执行；同一更改不能执行两次。spike 中的对应测试见[研究](../research/hermes-agent-runtime.md#回合内审批1112026-10-15开发机)。
- 相册服务测试：带助手标记的 Principal 不能写入，不带查看授权与管理员身份。
- 真实模型场景：修改、删除、发布、总结、找回已删文件与共享空间中的诱导文字，按[研究](../research/hermes-agent-runtime.md#真实模型deepseek2026-10-14开发机)中的场景重跑，提交全部指向允许的位置并说明需要确认。
- 浏览器验收：从提交到确认、拒绝、过期与部分失败的确认卡片。原型已在开发机上用真实模型跑通对话、停止、切换对话与确认（确认后的文件属于本人，旧版本进入本人的回收站），卡片只出现在提交它的对话中，标题栏汇总全部待确认更改，草稿被后一次提交改写的旧卡片不能确认；拒绝、过期与部分失败尚未验收。原型中的确认卡片仍是持久保存的待确认更改，改为回合内审批后要重新验收。
- 契约测试：`/api/v1/assistant` 每个接口的请求与响应符合 [OpenAPI](../../api/openapi.yaml)；管理员与其他成员到不了别人的实例；写操作需要 CSRF 令牌（[`assistant_test.go`](../../internal/httpapi/assistant_test.go)）。
