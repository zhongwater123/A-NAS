# 相册侧栏的“照片”改名“图库”

状态：decided（2026-10-20，用户）
更新时间：2026-11-05

## 问题

相册开放视频后（[决定](2026-10-19-videos-in-the-photo-library.md)），视频出现在侧栏的“照片”里。

## 选项

- **图库**：与顶栏的“我的图库”一致，即[领域语言](../../CONTEXT.md)中的受管图库。
- **相册**：已是应用名，也是侧栏下方用户自建的相册（Album），会混淆。

## 决定

用户 2026-10-20 提出视频出现在“照片”里不合理；名称按建议取“图库”（[PR #153](https://github.com/zhongwater123/A-NAS/pull/153)）。
