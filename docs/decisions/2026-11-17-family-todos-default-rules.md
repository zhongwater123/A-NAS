# 家庭待办规格中补充的默认规则

状态：pending
更新时间：2026-11-17

## 问题

[家庭待办规格](../specs/family-todos.md#本稿补充的默认规则)中“本稿补充的默认规则”是让实现和验收可以执行的设计建议，分一件待办、处理与重新打开、提醒三部分，例如类别、金额怎么记、处理完留多久、推迟天数、提醒档位的细节。其中标题长度和分档提醒沿用原型规则 22、23（见[原型规则的对应](../specs/family-todos.md#原型规则的对应)），“知道了”按人记等是 A-NAS 新补的。已按它们实现，用户还没有确认；用户定过的是[待办是本体能力、按来源分范围、桌宠只读汇总、先做第一步](2026-11-16-family-todos-first-step.md)。

## 选项

- **全部保留**：规格中的规则即为确定的行为。
- **逐项修改**：指出要改的规则，改动连同规格与代码一起提交。
