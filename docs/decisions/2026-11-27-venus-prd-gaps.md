# Venus PRD v3 没写清或前后矛盾的四处怎么做

状态：decided（2026-11-27，用户）
更新时间：2026-11-27

## 问题

[Venus 规格](../specs/venus.md)一律以《Venus PRD v3》为准，但 PRD 有四处没写清或前后矛盾。前三处决定接口契约和骨架的布局，要在写契约前定下来（[#690](https://github.com/zhongwater123/A-NAS/issues/690)）：

1. **示例作品**：开始页固定有一张示例作品（M1-1），PRD 没写所有成员共用一份还是每人一份，也没写能不能改、能不能导出。
2. **上传中断进哪个页面**：PRD 3.3 和 M5-1 写点开回准备页，附录 A.2 又把“上传中断 · 重新选择文件继续”放在成片页生成中态。
3. **900 宽以下**：M6-6 一边写“900 以下顶栏压缩、镜头轨横向滚动”，一边写“更窄显示‘请放大窗口’”；验收又要把窗口拉到 850 宽看效果。
4. **埋点**：M10-2 和 PRD 3.6 列了一张事件清单，存在哪里待定。

## 选项

- **示例作品**：所有成员共用一份、只读；或者每人复制一份、可以试改，但每个人都要多占一份素材的空间。
- **上传中断**：统一进准备页；或者留在成片页，只放一个“重新选择文件”的按钮。
- **900 以下**：850 仍可用；或者 900 以下就整页只显示“请放大窗口”。
- **埋点**：初版自己按清单埋点；或者先不做，用别的渠道看。

## 决定

2026-11-27 用户定：

1. **示例作品共用一份，只读**：“示例作品就共用一份，只读。”
2. **上传中断统一进准备页**，跳转时用提示条说明一次“上传中断，重新选择文件继续”。理由：重新选择文件、对清单只能在准备页做，成片页只放一个按钮，点了还是要跳过去。
3. **850 宽仍可用**：900 以下压缩顶栏，镜头轨在轨道内部横向滚动，整页不出横向滚动条；不足 720 宽才整页只显示“请放大窗口”。理由：这样和 PRD 的验收表一致，验收表是最具体的判断标准。
4. **埋点先不做**：“好像同事说要接入热力图观看用户交互的日志，至于模型那边有公司中台记录。”PRD 3.6 的事件清单留着，以后核对热力图和中台的记录够不够用时再看。
