# 网页搜索像人一样询问引擎

状态：decided（2026-11-02，用户）
更新时间：2026-11-05

## 问题

全家共用一个公网地址。搜索网站发现这个地址搜得比人快，或者被拦下后还在搜，就会封它，家里手机、电脑直接上这些网站时也会遇到验证码。

## 选项

未记录当时比较过的选项。

## 决定

用户 2026-11-02 要求“不希望 IP 被封，策略要更像人搜的”。按这个要求，产品服务按一个人在键盘前搜索的样子询问每个引擎，被网站拦截后暂停 1 小时起、最长 1 天；具体规则见[规格](../specs/web-search.md#像人一样搜索)。
