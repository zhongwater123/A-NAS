# OCR 分流的目标召回取 99%

状态：decided（2026-11-02，用户）
更新时间：2026-11-05

## 问题

只给可能有文字的照片读文字：用什么方法挑出这些照片，召回定在多高。

## 选项

见[分流评估](../research/photo-ocr-routing.md)：PP-OCRv6 检测，或照片已有向量的相似度。

## 决定

分流用照片已有的向量（PP-OCRv6 检测更差，不用）；目标召回取 99%（阈值 0.6926）。Claude 建议，用户 2026-11-02 确认（“按99%来，开始做步骤3”）。依据：方案要求召回接近 100%；漏掉的票据比多花的几小时一次性空闲 CPU 代价更大。
