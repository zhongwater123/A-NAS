# 程序坞图标悬停时显示窗口缩略图

状态：decided（2026-10-20，用户）
更新时间：2026-11-05

## 问题

鼠标停在程序坞的图标上时显示什么。

## 选项

- **窗口缩略图加关闭按钮**，与 Windows 任务栏相同。
- **名称与状态**。
- **实时摘要**。
- **静态说明**。

## 决定

用户选窗口缩略图加关闭按钮，并要求不重复造轮子（[PR #154](https://github.com/zhongwater123/A-NAS/pull/154)）。PR 中另列了四项实现时的默认值请用户确认：悬停 0.45 秒打开、离开 0.16 秒关闭，键盘聚焦也打开，✕ 直接关闭不再确认，打开期间缩略图不实时更新；PR 合并时没有记下用户对这四项的意见。
