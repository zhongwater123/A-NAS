# OCR 字段核对的单字概率取 0.99

状态：decided（2026-11-03，用户）
更新时间：2026-11-05

## 问题

读出的字段哪些可以自动通过，哪些标为“待核对”。验收指标是自动通过的字段中错误的比例。

## 选项

不同取值下的通过率与错误率见[核对层实测](../research/photo-ocr-model-evaluation.md#核对层实测qwen35-4b2026-11-02实施步骤-3)。取 0.9 时还会放过“看起来合法、错了一位”的号码，这正是核对要拦下的。

## 决定

Claude 建议 0.99，用户 2026-11-03 确认，实现为 `textMinConfidence`。确认时依据的数字是 45% 的字段自动通过、其中 4.7% 是错的；评审后改为在字段名之后取概率，同一批读取重算为 48% 通过、2.7% 是错的，真正读错约 0.3%。
