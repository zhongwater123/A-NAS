# 宿主机网络与手机直连热点的首版范围

状态：decided（2026-11-19，用户）
更新时间：2026-11-19

## 问题

在哪里验证网络设置与直连热点，首版覆盖哪些联网方式和手机访问场景。

## 选项

- 在宿主机 NAS 上验证，网线上网，独立无线网卡开热点，手机经浏览器访问 Web 桌面并上传。
- 在 RK3588 上验证，首版同时处理无线网卡并发、无网线样机及首次配网。
- 把 SMB 等协议也作为热点的首版入口。

## 决定

2026-11-19，用户选择宿主机 NAS 作为首台验收设备，要求首版由网线上网并开独立热点，优先把手机上传流程做完整。用户提出热点通过 Web 桌面访问。首版规格按这一访问方式设计，其他访问方式另行讨论。
