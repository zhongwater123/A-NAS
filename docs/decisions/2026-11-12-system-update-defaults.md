# 系统更新的默认做法

状态：decided（2026-11-12，用户）
更新时间：2026-11-12

## 问题

“设置 → 系统更新”（[规格](../specs/system-update.md)）要定几项默认做法：新版本是否自动下载、是否自动安装、谁能看到、能否回到上一版本，以及有新版本时在哪里提示。这些决定影响家里的设备在没人操作时会做什么。

## 选项

- **自动下载**：默认打开，发现新版本就在后台下载，不安装；或默认关闭，由管理员点“下载”。
- **自动安装**：默认关闭，由管理员点“安装”，打开后在每天 03:00–05:00 安装（镜像设备也在这个时段重启）；或默认打开。
- **谁能看到**：只有管理员，成员只在概览中看到产品版本；或成员也能看到更新状态。
- **回到上一版本**：提供，上一版本的模型与运行环境保留到下一次更新通过检查；或不提供，只保留安装失败时的自动回退。
- **提示位置**：概览的“需要处理什么”加一项“有新版本 X”，设置侧栏的“系统更新”带标记；或只在“系统更新”页中显示。

## 决定

用户 2026-11-12 选了每项的第一个选项（“按建议定”）：

- 自动下载默认打开；
- 自动安装默认关闭，打开后的时段默认 03:00–05:00；
- 只有管理员能看到并操作；
- 提供“回到上一版本”；
- 有新版本时在概览的“需要处理什么”与设置侧栏提示。

未记录其他理由。
