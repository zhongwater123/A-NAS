## 问题

README 声明“© 2026 A-NAS 作者。保留所有权利”（见[决定](2026-11-17-all-rights-reserved.md)）。还有三件事没定：

1. **著作权归谁**：个人还是单位。按《计算机软件保护条例》第十三条，软件如果是在任职期间为本职工作开发的，或者主要用了单位的资金和设备、由单位承担责任，著作权可能属于单位。
2. **其他提交者的授权**：截至 2026-11-17，main 上除了仓库所有者，还有 Wangjjeupu（160 次提交）、Mr-Trizzy（5 次）和 Frank（3 次）的提交。这些代码的著作权属于他们本人或其单位。没有书面授权，著作权人对这部分代码的权利不完整，以后商用或改发许可证都要逐一征得同意。
3. **`deploy/search/anas_search.py` 的许可证**：这个文件导入 SearXNG（AGPL-3.0），在 SearXNG 进程中运行，并由 `scripts/build-packages.sh` 装进软件包。随软件包分发时，它应按 AGPL-3.0 或与之兼容的许可证提供，不适用“保留所有权利”。

定下前，README 的著作权人暂写“A-NAS 作者”。本记录不是法律意见；涉及单位的，需要单位法务确认。

## 选项

著作权人：

- **个人**：README 写个人姓名或 GitHub 账号。
- **单位**：README 写单位名称，由单位法务确认。

贡献者授权：

- **书面确认加贡献者协议**：现有提交者书面确认，把各自贡献的著作权转让或授权给著作权人，包括改发许可证和商业授权的权利。之后的贡献者在 PR 模板中同意同样的条款。
- **暂不处理**：保持现状，以后商用或改许可证时再逐一联系。

`anas_search.py`：

- **AGPL-3.0-or-later**：与 SearXNG 一致。
- **MIT**：与 AGPL 兼容，限制最少。
