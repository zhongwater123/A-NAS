# 开机动画的风格

状态：decided（2026-10-08，用户）
更新时间：2026-11-05

## 问题

Web 桌面加载时先播放开机动画，主要面向 4:3 的本地控制台屏幕。动画用什么风格。

## 选项

- **80 年代电视台台标**：CRT 画面、日落配色，标志与字标在 4:3 画面上居中叠放。
- **VFD/14 段显示屏**的样子。
- **16:9 左图标右文字**，配青色霓虹手写字。

## 决定

用户 2026-10-08 选 80 年代电视台台标风格、日落配色与居中叠放。另两种没有采用：VFD 不是想要的台标风格；左右排版“融合感不强，右边太突兀”。用户明确喜欢嵌套折线的屋顶三角与条纹存储阵列组成的标志。当时字标下的“HOME STORAGE”只是占位，用户没有确认。
