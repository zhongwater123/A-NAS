# Web 桌面首屏 JavaScript 上限放宽到 200 kB

状态：decided（2026-10-30，用户）
更新时间：2026-11-05

## 问题

Web 桌面首屏的 JavaScript 有上限（[Web 桌面架构](../architecture/web-desktop.md)），原为 170 kB。

## 选项

未记录当时比较过的选项。

## 决定

2026-10-30 用户要求更丰富的交互，并同意家庭中心的七项交互升级（“都可以，开始做”），其中一项是把首屏 JavaScript 上限从 170 kB 放宽到 200 kB，给桌面外壳留出余量。
