# 本机型不支持的功能在界面上隐藏还是标注

状态：pending
更新时间：2026-11-18

## 问题

[设备分档](2026-11-18-device-tiers.md)之后，同一套系统会运行在硬件不同的设备上，有些功能在某台设备上用不了：硬件没有（例如没有 NPU）、资源不够，或者以后按档位取舍。现在各功能各自报告能不能用，界面也各自处理。需要定一个统一的做法，之后的规格与界面按它写；不定的话，同样的情况在不同功能里会表现得不一样。

## 选项

- **隐藏**：设备上用不了的功能不出现入口。界面简洁；但用户不知道这项功能存在，同一套说明在不同设备上对不上。
- **标注“本机型不支持”**：入口保留但不可用，并说明原因。用户知道设备之间的差别；但低端设备的界面上会多出一些用不了的入口。
