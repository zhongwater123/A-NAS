# 模型准入只看模型自身的许可

状态：decided（2026-10-10，用户）
更新时间：2026-11-05

## 问题

随系统交付的模型按什么许可准入：只看模型的代码与权重，还是连同训练数据集。

## 选项

未记录当时比较过的选项。

## 决定

用户 2026-10-10 确认：只看模型本身的许可，代码与发布的权重都必须允许商用和随产品再分发；训练数据集的许可不作准入条件，只记录在案；排除 AGPL/GPL、非商用权重和只提供 API 的模型。2026-10-13 用户对人物与宠物的模型重申这一条。训练数据来源在对外发行前核对。
