# 剪辑中心方案中补充的默认做法

状态：pending
更新时间：2026-11-17

## 问题

[剪辑中心规格](../specs/montage-center.md#本稿补充的默认规则)和[实施方案](../architecture/montage-center.md)为了能实现和验收，补了下面几项默认做法。它们是建议，用户还没有确认：

1. **推荐方案**：#514 要求“展示推荐方案，用户确认开始后生成”。配乐页显示素材数与总时长，默认选中本人上次用的歌（第一次用时选曲库第一首），用户确认后才开始。
2. **成片在相册里的样子**：
   - 存进本人个人图库的根目录；
   - 文件名为“<项目名> v<版本号>.mp4”；
   - 拍摄时间取素材里最晚的拍摄时间，所以成片在时间线上排在这批素材后面。
3. **分析结果保留多久**：一个视频没有任何未撤销的授权引用满 7 天后，相册删掉它的剪辑分析。
4. **桌面提示**：提示三件事：正在规划、成片已存进相册、需要处理。
5. **上传部分失败**：队列跑完后列出成功与失败的文件，失败的可以重试或跳过；只用上传成功的视频建项目。
6. **一次能交多少**：一次最多 500 个视频；一句话要求最多 200 字。
7. **活动记录**：首版不写。

## 选项

- **全部保留**：上面的做法即为确定的行为。
- **逐项修改**：指出要改的项，改动连同规格与实施方案一起提交。
