# 0006：相册使用受管图库与不可变内容对象

状态：accepted

A-NAS 相册把导入媒体复制到受管图库，以稳定照片资产 ID 表达用户可见身份和生命周期，并以内容哈希寻址的不可变对象保存原始字节。选择该方案而不是原地索引普通文件夹，是为了让权限、重复照片、回收站、备份、AI 重建和崩溃恢复服从同一套事务边界。

## 后果

- 导入成功后，受管图库是权威数据源；普通文件夹和 USB 中的来源文件不会被相册自动删除。
- 多个照片资产可以引用同一个不可变内容对象，但必须保留各自的图库归属、用户元数据、权限与删除状态。
- 内容对象只有在最后一个照片资产引用永久删除后才能回收；引用关系和垃圾回收由相册 Module 维护。
- 相册、虚拟目录、文件管理图库投影和 SMB/NFS 只暴露照片资产或导出表示，不暴露底层对象路径作为公共身份。
- 数据盘不可用或空间不足时，相册不得静默把原图长期写入系统盘。

## 未采用的方案

- 原地索引任意文件夹：外部重命名、权限变化和删除会绕开相册事务，难以保证稳定身份、回收站和备份一致性。
- 每个照片资产保存一份物理原图：语义简单，但相册复制和完全重复导入会无条件放大容量占用。
