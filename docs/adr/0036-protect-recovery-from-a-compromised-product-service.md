# 0036：恢复能力独立于产品服务，产品会话不授予不可逆销毁权

状态：proposed（2026-11-10）；安全目标已由设备所有者确认，以下职责拆分与迁移为具体提案，工程待实施。

用户要求产品服务失陷也不能造成用户数据不可恢复的损失。ADR 0008/0011 的独立进程与 UID 隔离仍有价值，但产品可写的身份库、可重放的真实会话以及能删除恢复点的管理 IPC，使这种隔离不足以满足新目标。决定方向为：把身份权威、受保护版本的保管与最终销毁授权移出产品服务的控制域，以容量和入口限制换取可验证的恢复保证。

## 决定

1. **身份权威独立**：新增非 root 身份服务，独占账号、凭据、会话、恢复与授权状态。产品服务只有非权威投影，不可写身份数据库、密钥或其父目录。Host Agent、文件代理、相册和容器代理验证可信签发者及具体操作权限，不能只检查 UDS 可连接或请求类型正确。
2. **普通会话不授予销毁权**：承认攻击者能滥用真实产品会话、控制产品页面。最终销毁、保护策略弱化、格式化、身份接管、Shell 和写挂载等操作由独立可信管理入口产生目标绑定、单次、短期授权；执行器自行核验并持久消费。首版以预先独立配置的 SSH 公钥认证配合 root 所有的本机管理工具实现；现有 Web PTY、产品登录密码和产品 Kiosk 页面均不能充当该入口。
3. **保护先于可变活动视图**：新增保护服务，独占历史版本、恢复集、引用图、销毁记录和预算。每次受保护提交确认成功前，必须持久保存恢复所需的数据与元数据。产品或相册的“清空”、复制去重与活跃引用归零都不能使它越过保护引用执行物理回收。
4. **保护版本没有普通自动过期**：产品调用、经过的时间、保留份数、攻击者产生的新版本以及磁盘压力，均不能淘汰仍受保护的版本。空间不足拒绝新写，保留恢复所需预算；明确接受存储增长与人工精简的代价。固定天数窗口不足以抵抗长期失陷。
5. **所有写入口统一纳入**：Web、相册、SMB、容器与终端必须满足同一受保护提交契约。未具备同步保护机制的入口只读或禁用。周期快照、inotify 和事后扫描不能充当尚未被保存的字节的保护手段。
6. **恢复不依赖产品服务**：数据、用户元数据、身份对应与密钥恢复材料组成版本化恢复集；提供独立列表、校验和恢复工具。丢失产品状态、重装系统盘或产品 UI 不可用都不阻断恢复。授权销毁的版本与被排除的故障范围按[规格](../specs/compromised-product-data-protection.md)明确界定。

## 取舍

- 保留单机、Go 模块和既有文件 ACL、相册 Policy；仅在需要隔离写权限的位置增加进程，不为每个应用拆服务。
- 可信计算基包含内核、身份/保护服务、必要的 Host Agent、相册权威写入模块及 Docker 控制面。不能声称抵御宿主机 root、内核或这些模块同时失陷；同盘快照也不抵御介质损坏。
- 普通操作可以改变活动数据，但其效果必须可恢复；读取到的明文仍可能被泄露。此决定不提供“零停机、零泄露、用户意图不可伪造”的额外承诺。
- 管理员经可信入口恢复成员账号的能力保留，并记录真正的恢复操作者；这不等于产品管理员会话可以接管身份或销毁历史，也不承诺防御拥有宿主机 root 的物理所有者。
- 首版禁止未保护的直写路径，可能暂时收紧 SMB 写入、Web 终端及容器共享写挂载。资格验收完成后逐项恢复；不能为保持原功能而静默降级安全目标。

## 未选择

- 仅把会话库移到 Host Agent：消除伪造会话，不消除真实会话滥用和删除恢复点。
- 继续在产品页面弹密码框、增加 CSRF 或由同页 JavaScript 签名：产品页面已不可信，不能证明真实用户确认。
- 每日快照与“保留最新 N 份”：可能丢失最近已确认写入，还能被长期等待或版本洪泛淘汰。
- 只给目录设置只读属性或使用 Btrfs 只读快照：持有 root/Docker 删除接口的调用方仍可通过其他路径销毁，需保护控制面一起隔离。
- 自动保留全部版本、空间不足时删除最旧版本：攻击者能主动制造这一条件，故拒绝这种回退。
