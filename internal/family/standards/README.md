# 家庭中心的参考数据

家庭中心随程序发布这两份数据。它们来自公开的官方文件，更新时按下面的来源重新核对，并在提交说明中写明版本。

## 生长标准

`growth/` 中是 WS/T 423—2022《7 岁以下儿童生长标准》附录 A 的百分位数值表（P3、P10、P25、P50、P75、P90、P97），每个指标、每个性别一份：

| 文件 | 标准中的表 | 年龄 |
|---|---|---|
| `weight-<sex>.csv` | 年龄别体重 | 0—81 月龄：24 月龄前每月一行，之后每 3 个月一行 |
| `height-<sex>.csv` | 年龄别身长/身高 | 同上；2 岁前为卧位身长，2 岁起为立位身高 |
| `head-<sex>.csv` | 年龄别头围 | 0—36 月龄：24 月龄前每月一行，之后每 3 个月一行 |

- 来源：国家卫生健康委发布的标准全文 PDF（2022-09-19 发布，2023-03-01 实施，代替 WS/T 423—2013），`https://www.nhc.gov.cn/cms-search/downFiles/e38068f0a62d4a1eb1bd451414444ec1.pdf`，SHA-256 `1fa2f1f0b299028063fc82b58920a2ea058a04aa2bd7e5bf3e17e64e77c067e5`。
- 转录核对（2026-10-29）：
  - 两种文本提取方式得到的数值完全一致；
  - 每行 P50 与附录 B 的中位数相同；
  - 每个百分位都落在同一行附录 B 标准差数值的舍入范围内；
  - 附录 B 与 MIT 许可的 `child-growth-eval` 2.1.0 中的表逐值相同。
- 标准不给 LMS 参数，两个取样年龄之间按线性插值，见 [`growth.go`](../growth.go)。
- 国家卫生健康委 2024 年的婴幼儿喂养评估指南（国卫办妇幼函〔2024〕452 号）附件中的身长/身高表与 WHO 2006 标准一致，与本标准不同；家庭中心按[规格](../../../docs/specs/family-center.md)使用本标准。

## 疫苗程序

`vaccines.json` 是家庭中心的疫苗目录：

- 免疫规划疫苗（`programme: true`）来自国家疾控局、国家卫生健康委《国家免疫规划疫苗儿童免疫程序及说明（2026年版）》（国疾控卫免发〔2026〕16 号，2026-06-17 印发），`https://www.ndcpa.gov.cn/jbkzzx/c100014/2073005020766703616/BXZA3kH5.pdf`。
  - 脊灰与流脑按程序表的剂次连续编号：脊灰第 1、2 剂为 IPV，第 3、4 剂为 bOPV；流脑第 1、2 剂为 MPSV-A，第 3、4 剂为 MPSV-AC。
  - 乙脑、甲肝各有两种程序，由各地选用其一，以 `group` 表示；默认用减毒活疫苗，家庭可以改选。
  - 白破疫苗只用于 7—11 周岁补种，不在常规程序中。
- `covers` 依据说明第二部分的替代规定：按说明书接种含百日咳成分、含 IPV 成分的非免疫规划疫苗，“可视为完成相应剂次”；流脑结合疫苗在 24 月龄前完成全程的，可视为完成 MPSV-A 的剂次（`coversUpTo: 2`）。
- 非免疫规划疫苗的程序参考《贵州省非免疫规划疫苗接种方案（2024年版）》，只作为计划提醒，以产品说明书和接种门诊为准。全国没有统一的自费疫苗程序。
