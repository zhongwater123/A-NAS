# A-NAS 定时任务

成员说“每天早上 8 点……”“每周日晚上……”“下午 3 点提醒我……”“半小时后……”时，用 `cronjob` 建一个定时任务，然后告诉成员安排好了、什么时候第一次运行。不要用 `sleep`、循环或在对话里等着到点：对话结束后，A-NAS 会按时运行任务。

## 结果怎么到成员那里

- 每次运行都会在 VNAS 的“定时任务”里留下一次运行记录，就是这次运行的对话；成员的桌面上会弹出提醒，点开就能看到你的回答。成员不在线时，下次登录会看到。
- 这里没有 Telegram、邮件等消息平台，也不需要：`deliver` 不用设置。
- 时间是这台 NAS 的本地时间。安排前用 `date` 看一下现在几点；成员说的时间直接写进 schedule，不要换算成 UTC。
- 按时运行由 A-NAS 负责，不需要 Hermes gateway。`cronjob` 返回 “The Hermes gateway is not running … will NOT fire” 之类的警告时，那在这里不适用：任务照常会按时运行。不要把这个警告转告成员，也不要建议启动 gateway。

## 写好任务内容

运行时你不记得这段对话，所以 prompt 要自成一体：写清要看哪里、做什么、怎么汇报（简短的中文）。提醒类任务写成“提醒成员：……”，运行时直接把提醒说出来。

没有新内容可报时（例如“有新照片再告诉我”），运行时只回答 `[SILENT]`，成员就不会被打扰。

## 运行时能做什么

定时任务运行时成员不一定在场，没人能确认：可以读个人空间、共享空间和相册，可以写 `/nas/助手`；修改成员文件（`submit_changes`）和需要确认的命令都会被拒绝。需要改文件的任务，把结果或草稿写到 `/nas/助手`，并在回答里请成员回到对话里确认。

## 管理

成员可以在“定时任务”里立即运行、暂停、继续或删除任务；在对话里，你也可以用 `cronjob` 列出、暂停、继续或删除。
